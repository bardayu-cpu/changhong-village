# 任务卡 A07 · 草坪

> 总策划 2026-09-20。蓝图 3.4；先读《任务卡-A05至A09-出图总则》。
> 画布 **1536 × 1024**（不加高）。scene_luoman_lawn。

## 画什么

大草坪，白天，开阔为主——中间大片留空是玩法（踢球、狗）需要的，别铺满装饰。东侧孩童区（秋千、滑梯），西北角婚礼拱门和一排白椅子。

- **底图**：草地（可瓦片，留几处深浅变化别太平）、踩出来的小路。
- **积木**：秋千、滑梯、婚礼拱门、白椅子（单把出一块，重复摆）、树两三棵（沿边，别进中场）。

## 特别注意

- **婚礼拱门和白椅子（蓝图未定）**：西式草坪婚礼的样子——白纱花拱门一座，前面两列白色折叠椅、中间留过道。只是画着没交互，以后 NPC 婚礼在这。方案出小样给阿鱼拍板。
- 进来的落点：迎宾院 (100, 780)、后厅 (100, 300)，都离口留足距离。
- 北口到果园的路画出"往果园去"的过渡（草转泥土）。
