## 1. 怎么打开、怎么跑

- 引擎：**Godot 4.7.2**（`/Applications/Godot.app`，版本号 `4.7.2.stable.official`）。别的版本可能打不开或者表现不一样。
- 下面的命令都在解压出来的 `godot/` 目录里跑。`G=/Applications/Godot.app/Contents/MacOS/Godot`。

**第一次打开：先导入，要等满 600 秒。**

```
$G --headless --editor --quit-after 600 --path .
```

- 导入会生成 `.godot/` 缓存，zip 里没带，第一次一定要跑这一步。
- 跑完把输出存下来，查「Scan thread aborted」，**必须是 0 次**。不是 0 就是导入没完成，图会缺，再跑一遍。

**正常玩：**

```
$G --path . --resolution 540x960
```

**直接进后厅，不用从开场一路走过去（开发用）：**

```
$G --path . --resolution 540x960 -- --start=backhall --backhall=start --hud
```

- `--start=backhall`：跳过开场，从宴会厅侧门（第 65 版起是西侧门）直接进后厅，人能接着走。
- `--backhall=start`：后厅换成**空的起点**（见第 3 节）。不带它就是现在的灰盒后厅。
- `--hud`：带调试面板（帧率、日志）。

**截图（手机竖屏）：**

```
$G --path . --resolution 540x960 -- --backhall=start --capture=<存图的文件夹> --shot=backhall
```

- 截完自己退出，图存成 `<文件夹>/backhall.png`。
- 别的截图名字在 `scripts/main.gd` 的 `_setup_shot` 里，后厅相关的有 `backhall`、`backhall_overview`（整张，要用 `--resolution 1536x1024`）、`backhall_dress`、`backhall_lounge`、`backhall_mahjong`、`backhall_pot`、`backhall_lawn`。
- 你加了新地方，可以照样在 `_setup_shot` 里加一个名字。

## 2. 怎么跑测试

**客户端测试**：`tools/test_*.gd`，一个一个跑，每个最后一行是 `RESULT PASS` 才算过。

```
for f in tools/test_*.gd; do
  $G --headless --path . --script res://$f > /tmp/t.log 2>&1
  grep -q "^RESULT PASS" /tmp/t.log && ! grep -aq "Parse Error\|Compile Error\|Failed to load script" /tmp/t.log \
    && echo "过 $f" || echo "没过 $f"
done
```

- **test_map.gd 本来就没有 RESULT 那一行**（它只打印地图），它「没过」是正常的。
- 光看 RESULT 不够：脚本有语法错时测试可能照样打出 PASS，所以上面同时查了 Parse Error、Compile Error、Failed to load script。
- 现在这份：除 test_map 以外 **30 个全过**。后厅相关的是 `test_backhall.gd`（灰盒后厅）和 `test_backhall_start.gd`（空起点）。
- 你改了后厅以后，`test_backhall.gd` 多半会不过（它查的是灰盒的四个房间）。照你的新后厅改它，或者新写一个 `test_kitchen.gd`。**别的测试不能因为你的改动变成不过。**

**桥测试**（游戏跟微信那一层传话用的，改了 cloud.gd 才需要）：`zsh tools/test_bridge.sh`，最后是 `RESULT PASS`。

## 4. 宴会厅 ↔ 后厅 ↔ 草坪，现在怎么接

全在 `scripts/main.gd`：
（第 65 版方案 C 起的位置）
- **宴会厅 → 后厅**：宴会厅**西侧门**（宴会厅场景里的 `side_door` 点，(40, 1300)）。人走进它的半径，`main._process` 调 `_switch_canvas("backhall")`。进来站在走廊东头 `to_hall` 往里 70 像素，(1436, 780)（`BACKHALL_FROM_HALL` 也是这个数）。
- **后厅 → 宴会厅**：后厅里 id 叫 `to_hall` 的点，**走廊东头** (1496, 780)，半径 50。`_on_backhall_spot` 收到它就回宴会厅，人站在西侧门里边 (104, 1300)。
- **后厅 → 草坪**：id 叫 `to_lawn` 的点（厨房后门），**走廊西头** (40, 780)，半径 50。
- **草坪 → 后厅**：草坪的 `to_backhall` 点（草坪东边北头）。进来站在 `to_lawn` 往里 70 像素，(110, 780) 附近（`BACKHALL_FROM_LAWN` 是 (100, 780)）。
- **后厅 → 西餐厨房**：走廊南边厨房底下 `to_wkitchen` (264, 990)；去喷泉广场的 `to_plaza` 在 (896, 990)。
- 10/4 连图起，「进来站哪」先照布局里对面那个口往里 70 像素算，算不出来才用 main.gd 开头那几个常量。
- 进来刚好站在某个点里，不会马上被弹回去：要先走出那个点的半径一次才算（entrance.gd 里的 inside_spot）。

**新后厅只要保住三样，进出就不用动 main**：
1. 还叫 `to_hall`、`to_lawn` 这两个点；
2. 两个口往里 70 像素那两处（第 65 版起是 (1436, 780)、(110, 780) 附近）能走；
3. 场景还是 entrance.gd 那一套（继承它）。

要挪出口或者进来站的地方，就一起改 main.gd 开头的 `BACKHALL_FROM_HALL`、`BACKHALL_FROM_LAWN`。

**要是厨房想做成单独一块画布**（不在后厅里，而是从后厅再走进一扇门），要在 main.gd 里加的地方：
- `_in_scene` 里的名字表；
- `_show_canvas` 里的 canvases 表；
- `_goto` 里 hud 那一行的名字表；
- `_switch_canvas` 里加一段 `elif to == "kitchen"`；
- 照 `_on_backhall_spot` 写一个 `_on_kitchen_spot`。

能不分就不分，放在后厅这块画布里最省事。
