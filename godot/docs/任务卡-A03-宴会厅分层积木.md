## 二、规矩

1. **叠起来必须和原图一样**：在 base.png 上盖上所有积木，结果要和 approved_preview_v4.png 一样。所有图都是 1672×941，不许挪位置、缩放、改透视、改颜色
2. **积木要完整**：原图里一件东西被另一件挡住的部分（比如桌子一角被前面的花架挡住），要补画完整，因为人可能站在它俩中间
3. **底图要补全**：人走到桌子后面时，看到的是桌子后面的地面和地毯，所以底图上每件积木原来的位置都要补画出地面和地毯
4. **边缘干净**：透明只有全透明和不透明两种，没有半透明毛边
5. **walk.png**：白色是人能站的地面；桌椅脚下、灯笼和花架的底座、屏风、栏杆、墙、舞台（包括台阶）都画黑。白色区域要连成一片，从红毯最下面能走到主桌前
6. **不画人**；不改原图的风格；除了囍不写字

## 三、scene.json

坐标都是原图上的像素，x 向右、y 向下：

```json
{
  "scene": "scene_roman_banquet",
  "revision": "v6",
  "size": [1672, 941],
  "person_px": {"near_y": 900, "near_h": 105, "far_y": 330, "far_h": 70},
  "spawn": [836, 905],
  "couple": [836, 318],
  "points": [
    {"id": "couple_table", "x": 836, "y": 440, "r": 70, "kind": "talk", "line": "table"},
    {"id": "door", "x": 836, "y": 925, "r": 60, "kind": "door", "line": "leave"}
  ]
}
```

- `person_px`：一个 1.75 米高的人，脚站在 near_y 那一行时画多少像素高、站在 far_y 那一行时画多少像素高。按原图里椅子的大小估，上面的数是我估的，请你按图核对后改
- `spawn`：进场时人站的位置（红毯最下面），写脚的位置
- `couple`：新人站的位置（主桌后面），写脚的位置
- `points`：走进半径 r（像素）就触发。couple_table 在主桌正前方的红毯上，door 在红毯最下面
