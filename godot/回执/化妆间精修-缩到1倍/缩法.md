# GPT 精修图缩到 1 倍的缩法（总002，10/5）

> 阿鱼 10/5 晚：「那不行，还是要用统一画风」（看了「2 倍家具会比人细」那条之后，总001 转）。所以 GPT 精修图进游戏照画风页第 0 节：**1 个美术像素 = 1 个画布像素**，跟人物、代码画同一种颗粒，1 倍、硬边。GPT 的 4 倍原图照样留着复用（留在共用文件夹 GPT 交的文件夹里，不进 git）。
> 拿化妆间已经交的 10 件（底图 + 上排化妆台、花架、角柜）试了 6 种缩法，试验图在这个文件夹里。以后别的场景用 GPT 精修，照这个缩。

## 定的缩法（试验里的 G）

1. **4 倍 → 1 倍用最近邻**（每 4×4 取一个像素）。GPT 这批图本身就是按大像素块画的，最近邻能留住硬边；面积平均会把边抹软、变成平滑画（试验 2 里 C、D、E 明显发糊）
2. **整间一套调色板，限 64 色**：底图和全部零件先各自缩到 1 倍，拼成一张取色（八叉树、**不抖动**），再把每张都压到这 64 色。64 色守画风页第 0 节「每块画布最多 64 色」；跟 96 色并排看几乎没差别（试验 3）。别用中位切分法取色：64 色时镜子的蓝被吃掉、变成灰的（试验 1 的 B）
3. **透明压成全透或全不透**：缩完透明度 ≥128 算不透明，其余全透
4. 位置照零件表：每件放在 (x/4, y/4)，底边落在 foot_y/4；按 foot_y 排前后

## 过不过看什么

- 缩完拼回整间，人（84 高的宾客）站在化妆台前，按手机 540×960 截一张，跟对话框定稿图、Claude 代码画那版并排比：颗粒一样粗、边是硬的、没有一片糊的
- 台面上的瓶瓶罐罐到 1 倍会很密、一粒一粒的，这是 1 倍颗粒本来的样子；挤成一团看不出是什么的，记下来请 GPT 那件少摆几样、摆大一点
- 过 scale-check 量比例；过提交前检查（透明 0/255）

def shrink(im):                     # 4 倍 -> 1 倍，最近邻
    im = im.convert("RGBA")
    s = im.resize((im.width // 4, im.height // 4), Image.NEAREST)
    a = s.getchannel("A").point(lambda v: 255 if v >= 128 else 0)
    return s.convert("RGB"), a
