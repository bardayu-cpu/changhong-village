## 这片场景是什么

罗曼山庄迎宾院，婚礼当天白天。客人进门先到这儿：签到、送礼金、拿喜糖、在花墙前拍张照，旁边有个休息的角落。

画布 `002-迎宾院`，1536 × 1024。这一片占**院子的东半边**，具体位置照该画布「交接」里的 `对照图-迎宾院-灰盒俯视-v2.png`（黄圈是玩家操作的点，坐标标在旁边）。

## 场景里有什么，每样在玩法里干什么

| 元素 | 玩家在这儿干什么 |
| --- | --- |
| **签到桌** | 走过去点「签到」→ 填名字（默认昵称，能改）→ 选礼金（不送 / 66 / 88 / 188 / 自己填）→ 确认。签过以后再进来只显示「已签到」。**桌面要看得出是办事的台子**——摊开的签到簿、笔、收礼金的地方 |
| **新娘爸爸** | 站在签到桌后面收礼金。收下说「收到啦～」，选不送说「人来了就好」 |
| **喜糖** | 签完自动给一颗，弹一次「喜糖收好了」。桌上要有一盘／一盒喜糖看得见 |
| **回忆册台** | 签到桌旁边一个台子，上面摊着一本册子。**现在是灰的、"还没印好"的态**——等阿鱼给六张照片才印得出来，所以这本册子要能画成"空着／没印好"的样子 |
| **花墙** | 合影的背景。**墙前面必须留出空地给人站**（玩家走进站位才会出「拍一张」） |
| **拍照站位** | 花墙前的地面，一块地毯或一圈标记，让玩家知道"站这儿拍" |
| **摄影师 + 相机（三脚架）** | 玩家点「拍一张」→ 选姿势（站好 / 招手 / 比心）→ 屏幕上两个圈往一起收，对上的那一下点下去 → 拍成。**相机要朝着站位**，摄影师在相机后面 |
| **印相纸的机器** | 拍成之后出一张相纸。机器摆在签到桌那一头，**要看得出纸从哪儿出来**；旁边可以摊着已经出来的相纸 |
| **相纸** | 拍出来的照片，**最多留 3 张**。要一张单独的小图（游戏里会摆出来、也会在界面里显示） |
| **休息区桌椅** | 一个老人坐这儿。玩家走过去他说一句乐山话「席上有翘jio儿 记得多吃两碗」 |
| **休息区老人** | 坐着，不走动 |
| **灯笼、花、红毯、屏风这些** | 纯氛围，没有交互。婚礼当天的喜庆感靠它们 |
| **通往宴会厅的楼门门脸** | 往北走进宴会厅 |
| **东小径** | 往东去草坪，要看得出是条路 |

- PNG 透明底，**alpha 只有 0 和 255**（不要半透明边、不要棋盘格假透明）
