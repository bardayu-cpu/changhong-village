## 这一版有什么（跟第 64 版比，玩家看得见的）

整张山庄照 `godot/回执/方向方案C-上下翻-1004.png` 摆：前门在最南，湖和小山在最北，草坪在西。第 64 版的东西两边整体对调，南北不变。

- **后厅三间整间平移**：从西到东依次是中餐厨房（后厨）、麻将室、休息室、化妆间，化妆间挨着宴会厅。每间屋里的画一笔没改（逐点比过，只差门牌位置和休息室叔叔起身走动），只是换了位置。隔墙还是一道，没有变成双层。
  - 走廊东头回宴会厅，西头是厨房后门、去草坪；
  - 走廊南边去西餐厨房的口在厨房底下，去喷泉广场的口在休息室门口西边；
  - 化妆间门洞离走廊东头「回宴会厅」牌太近，化妆间门牌挂到门洞西边。另外三块照旧挂在门洞东边。
- **宴会厅两道侧门对换去处**：西墙那道去后厅，原画里画了门板的东侧门去后花园。下面几样跟着西墙那道门走：
  - 「后厅」门牌；
  - 第一次坐下以后亮的金光和金箭头；
  - 进厅小卡那行，改成「西边侧门通后厅，厨房在那边」。
- **湖边只换了口**：
  - 东头南墙月亮门去后花园；
  - 湖岸小路西头尽头去果园 A；
  - 西头月亮门不通哪了，门洞留着，能走到南墙外。
- **果园重摆**：B 枇杷在西，A 草莓在东，牌子跟着换边。具体做法：
  - 北边田埂往南的地面整片左右翻；
  - 草莓垄、枇杷树、稻草人、篮子、收购摊、板车照原样画、不翻，各自挪到对面同样的位置，所以光还是从左上来，影子照新位置重新算；
  - 去湖边的口在东边，去后门的口在 B 北边。
  - 「果园 B」牌、「去后门」牌原来被树冠挡了一半（第 64 版就这样），顺手挪到两棵树中间的空当。
- **草坪的口挪到东边**：东边 y 450 往南全是树冠，三个口挤在北段空当，由北往南是后厅、西餐厨房、喷泉广场。
  - 「去果园 B」挪到北边西头两棵树干中间；
  - 「去果园 A」还在北边那条小路上，没动；
  - 「去儿童乐园」还在南边，没动。
- **迎宾院**：口的位置没动、只换了去处，免得跟画打架。西北口去喷泉广场，东小径去停车场。
- **喷泉广场**：东边去迎宾院、前门，西边去草坪、西餐厨房，南边从西到东是儿童乐园、小卖部、休息区 2，北边后厅。
- **停车场整块左右翻**：路在西，车位在东，去迎宾院、前门的两个口在西边，下车站在自己车的西边。洗手间在西、杂物处在东，照方案 C 图。
- **前门**：西口去喷泉广场，东口去停车场，门卫亭挪到西边。
- **七块灰盒**的口照方案 C 换边：
  - 儿童乐园：北边东口去广场、北边西口去草坪、东口去小卖部；
  - 小卖部：西去儿童乐园、东去休息区 2；
  - 西餐厨房：西去草坪、东去广场；
  - 后花园：西去宴会厅、北去湖边。
- **开车路线跟着翻**：车从前门开进来往西拐 → 喷泉广场从东边进、绕一圈从东边出 → 停车场从西口进，倒进自己的车位。
- **第 64 版做好的都还在**：自动开车（看过一次点一下跳过）、走到头提示、湖边能走、牌子不盖人、对话选项不被盖。
