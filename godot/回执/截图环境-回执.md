## 验收

| 项 | 结果 |
| --- | --- |
| **从干净状态一条命令到出图** | **验过**。原来没有 shot 这个 worktree，`zsh godot/tools/shot.sh 58c1a7f --out=…` 一条命令：建 worktree → 导入 → 核过 → 截，一共 18 秒 |
| **03 的北边 1:1 图用新入口重出一张，跟原来逐像素一样** | **验过**。跟 03 的提交 `58c1a7f` 同一提交、默认参数（北边 0,0,1536,1024、一比一、不放人、没界面），跟 `回执/出图-宴会厅北/宴会厅北-现状.png` 比，1536×1024 里**不一样的像素 0 个** |
| **导入不全时报错** | **验过**，三种都拦下、退出码 2、不出图：①导入日志里有 `Scan thread aborted`（拿假 Godot 打这一行）；②`.import` 指的导入结果不在（删掉 55 桌厅底图的导入结果、导入不重跑）；③有图没有 `.import`（多放一张没导过的图）。③是直接拿核对那段测的：shot.sh 换提交前会清掉 worktree 里多出来的文件，现实里这种图只会来自提交本身 |
| 换提交、别的参数 | **验过**。切到今天的 `00e228f` 重新导入、核过；带人带界面开席那张（540×960）、整厅 1/4 那张（384×860）都出得来，画面正常 |
