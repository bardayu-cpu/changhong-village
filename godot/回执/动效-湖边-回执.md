# 动效第 2 件：湖边（湖面波光 + 小船起伏）· 回执

> 05，2026-10-04，dongxiao-lake 分支（从 main e8c60a2 拉；第 66 版湖边东西两半都是像素画）。01 H 派：只上两样，做完截图给 01、停；不合 main、不出码。
> 石灯笼、湖心亭的灯等阿鱼看完宴会厅宫灯再定节奏；水鸟排后面。

## 结论

- **湖面波光**：东西两半的水面上，隔一阵冒出一小段 2～4 格长的横亮线，一秒换 3 拍，位置每拍不同。
  - 亮线的格子换成同一色带里亮一档的颜色：主水色 (108,143,189) → 浅倒影色 (176,198,222)，深水纹 (56,90,144) → 主水色。都是那两张像素画本来有的颜色。
  - 整格、全不透明，没有半透明糊边，不读屏幕。
- **小船起伏**：五条船（西边两条手划船、两条天鹅船，东边篷船）各自整格往上 1 像素、再放回来，一上一下一圈 1.6～2.4 秒，各条错开。

## 做了什么、挂在哪

| 文件 | 是什么 |
| --- | --- |
| `shaders/water_glint.gdshader` | 波光着色器：把背景水面那块再画一遍，只留亮线那几格，换成亮一档的颜色，其余丢掉（全透明） |
| `scripts/ambient/water_glint.gd` | 一块水面一个节点：用背景同一张图、只取水面那一块（`region`），贴在背景后面一个（背景上面、人和船下面） |
| `scripts/ambient/boat_bob.gd` | 小船起伏：只挪图（offset），不挪着地线，跟人排前后不变；船本来就在画，不多画 |
| `scripts/ambient/ambient.gd` | 总节点认得 `water_glint`、`bob` 两种配置；照节点名找背景、船 |
| `data/ambient.json` | 加 `scene_luoman_lake`：两块水面（`px_background_lake_west / east` 上 (0,300) 起 1536×486）、两对颜色、亮的机会 0.05、一秒 3 拍、格子 12×6；五条船的名字、一圈 1.6～2.4 秒 |
| `scripts/entrance.gd` | **改 1 行**：`build()` 里 `_exit_mark()` 后面挂动效（`Ambient` 是 layered_hall 里已经引的）。迎宾院、草坪、果园这些画布配置里没写，不挂 |
| `tools/test_ambient_lake.gd` | 新测试，26 项 |
| `tools/perf_lake_draws.gd` | 量每帧多画几次（照 03 的 `perf_lamp_draws.gd` 量法） |

## 降级

照公共架子：1 档波光亮的机会减半；0 档（全关）波光藏掉、船回原位。不在湖边整块不跑。

## 验过

| 项 | 结果 |
| --- | --- |
| 测试 `test_ambient_lake.gd` | 26 项全过：两块波光位置、层次、范围、整格；换的颜色是原图本来有的、比原色亮；五条船都找到、只在 0 和 1 像素之间换、挪图不挪着地线、各条错开；1 档减半、0 档藏掉和船回原位；切走就停 |
| 全套测试 | 87 过；test_map.gd 照旧没有 RESULT 行（本来就这样） |
| 截图（手机 540×960、长屏 1170×2532） | `动效-湖边/`：东西两半改前改后、长屏东西各一张；东西两半各放大 3 倍连拍 4 拍，看得出亮线换位置 |
| 整格核对 | 拿同一位置挂和不挂的截图逐格比：水色格子变了的，颜色全是那两种亮一档的颜色（东 157～218 格、西 249～331 格一拍）；其余变了的是船和人往上挪 1 像素露出的深色描边，不是波光 |
| **每帧多画几次**（`perf_lake_draws.gd`：同一位置关 / 开来回 3 轮，每轮 90 帧取中位） | 东半边 78 → 79，西半边 80 → 81，**都多 1 次**（视野里只有一块水面）。对象数也多 1 |
| 帧用时（电脑上，量了两回） | 东半边开了慢 1.1～2.0 毫秒，西半边反而快 0.3～0.7 毫秒，电脑上浮动大，下不了结论。波光着色器要在整块水面上每格算一遍，手机上要量 |
| 包体 | 进包的只有着色器和两个脚本、配置多几行，约 7 KB；不加图。见 `包体记录.md` |

## 没验成（要真机）

- 真机帧率：波光着色器要在视野里整块水面上每格跑一遍（东边约 540×466 格）。低端机掉帧会自动降档、全关，但要真机看
- 亮线一秒换 3 拍，手机上像不像水光、会不会太碎
- 船往上提 1 像素时，倒影是画在背景里的不跟着动，船和倒影之间可能露出 1 像素的缝，要阿鱼在手机上看

## 宫灯那条（记着，等阿鱼看完手机一起改）

03 量宫灯是视野里 14 盏多画 14 次（`测-liantu01-第66版.md` 第三节）。我回执里写的「108 → 110」是平滑光那一版、站在灯少的地方量的。改成像素光以后，三种大小是三张图，相邻两盏用不同的图就多画一次。改法是把三种大小拼进一张图，所有灯一次画完。

## 给阿鱼

湖边的水现在会闪了：水面上一小段一小段的亮光一闪一闪，换着地方出现，跟水在动一样；五条小船也会轻轻地一上一下。都是像素一格一格的，跟画面一个风格。手机一卡就会少闪一些，卡得厉害就停。你在手机上看看闪得是太碎、太少，还是正好。
