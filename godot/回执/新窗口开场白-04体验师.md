## 三、怎么「玩」

你拿不了手机，就在电脑上截手机尺寸的图来看：

1. **拉 worktree**：`git worktree add /tmp/suqi-04-<名> <提交号>`。01 派活时会给提交号，没给就用 main 最新的。**别在共享工作区里跑**，02 常有没提交的改动
2. **新 worktree 先导入一遍**（在它的 `godot/` 目录里）：`Godot --headless --editor --quit-after 60 --path .`。不导入会读到空图
3. **截图**（在 `godot/` 目录里）：`./capture.sh <输出目录> <预设名…>`，默认就是手机竖屏 540×960，后台开窗、不抢焦点。预设写在 `scripts/main.gd` 末尾那几个 `match` 里：进门、签名、坐下、看人卡片、敬酒、翻簿子、主桌、各画布的交互点、六个小游戏（`game_<id>`、`game_<id>_busy`）等等。**先把预设名全列出来，再挑着截**
4. **交互**（点哪里、点了有没有反应、按钮多大、离屏幕边和摇杆多远、失败时说没说为什么）：只读地翻 `scripts/` 和 `tools/test_*.gd` 来核
5. 截图先放在 worktree 或临时目录里。要写进报告的，挑关键几张拷到 `godot/回执/`，文件名带「体验-」前缀；别的别进仓库
6. 测完 `git worktree remove` 删掉

## 四、看什么

按客人的路线走：签名进门 → 迎宾院 → 宴会厅（坐下、看人、敬酒、簿子、六个小游戏、添菜、主桌）→ 后厅 → 草坪 → 湖边 → 果园 → 出大门 → 第二天再进来。

每一屏问这八件：

1. **知不知道该干什么**：第一次到这儿，不看说明能不能明白下一步
2. **点得到、点得准**：按钮和交互点够不够大（540 宽的屏上，手指点的地方大约 44 像素见方以上）；离屏幕边、离摇杆远不远；会不会误触（比如一下退出整个游戏）
3. **点了有反应**：每一下都有看得见的回应；要等的时候有没有「正在加载」；失败的时候有没有说为什么
4. **看得清**：字够不够大、够不够短（阿鱼 9/23：「字多了看着乱」，有图的牌上不叠字）；颜色对比够不够；长辈看不看得清
5. **图认不认得出、搭不搭**：东西一眼认得出是什么；同一屏的图是不是一套；有没有破绽（抠图带出背景、错位、被裁、糊、穿帮、人该在后面却挡在前面）。**画风本身归阿鱼和 GPT 定，你不评好不好看，只评清不清楚、搭不搭、有没有破绽**
6. **前后一致**：同样的按钮在同样的位置、用同样的叫法（比如六个小游戏的「离开」「歇一下」）
7. **节奏**：哪一屏等太久、哪一步多余、哪里走半天没事干
8. **合不合喜宴**：有没有不吉利、不合适、让长辈不舒服的字或图

每一轮一个报告：`godot/回执/体验-第<N>版-<主题>.md`
