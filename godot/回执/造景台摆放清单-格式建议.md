# 造景台摆放清单 placement JSON：02 要的格式（给 01 转 GPT，9/30 晚）

01 那份「目的」里第 4 样摆放清单写了：文件、脚点、前后层次、朝向、动作。02 照清单往游戏里摆，**还缺下面这几样**，没有的话还得回去量、猜。

## 要加的

1. **零件图里哪一点是「脚点」**（anchor）
   - 只给效果图里的脚点坐标不够，还要知道零件 PNG 里哪个像素对着那一点（比如桌子是图下沿正中，还是桌心）。
   - 每个文件写一次就行，放 `files` 里。
2. **缩放**：零件是不是 1:1 放的。原则上都 1:1；万一有缩放，写 `scale`，不写就当 1。
3. **地上占多大**（footprint）：每种零件在地上挡路的那一块（脚底下的椭圆或矩形，效果图像素）。
   - 画出来的框比地上占的大（桌子上面冒出椅背、灯柱上面冒出灯笼），走路要按地上那块算。
   - 每个文件写一次。
4. **桌子的座位**（seats）：每种桌的零件里，每把椅子坐人的点（相对脚点）和人朝哪。
   - 游戏里人要坐下、起身、换座，得知道椅子在哪。
   - 图里坐着的人要写坐的是哪张桌（桌的 id）、第几把椅子。
5. **动作图怎么切**（sheets）：每张动作图一格多大、每个动作（走路四个朝向、坐着吃、举杯、演奏）在第几行第几格、几格、每秒几格、一格里脚点在哪。
6. **背景上哪里不能走**（blocked）：墙、台子、乐队台、画在背景里的大件（礼物架、钢琴）挡路的范围。
   - 给多边形或者一张黑白遮罩 PNG（白能走、黑不能走），跟效果图一样大。
7. **每件东西一个 id**，跟种类分开写：桌子要能标出哪张是主桌，人要能标出新郎、新娘、乐手。
8. **图的基本信息**：效果图宽高、背景文件名、站着的人多高（像素），一张清单写一次。
9. **层次**：默认按脚点 y 排（越往下越在前），这点写明。只有例外的（贴在墙上的、飘在头顶的）才写 `layer`。

## 例子（字段名 GPT 可以改，意思要在）

```json
{
  "scene": "banquet55_scene_v1",
  "image": {"file": "素材图/preview_banquet55_scene_v1.png", "w": 1536, "h": 1024},
  "background": "积木/base_banquet55_scene_v1.png",
  "person_px": 110,
  "units": "效果图像素，左上角 (0,0)，y 往下",
  "sort": "按 foot 的 y 从小到大画，layer 写了的例外",
  "blocked": {"mask": "交接/walkmask_banquet55_scene_v1.png"},
  "files": {
    "blk_table_v1.png": {
      "anchor": [90, 148], "footprint": {"ellipse": [0, -40, 146, 100]},
      "seats": [{"no": 1, "at": [0, -92], "face": "down"}, {"no": 2, "at": [36, -84], "face": "down_left"}]
    },
    "blk_lamp_v1.png": {"anchor": [24, 110], "footprint": {"rect": [-12, -14, 25, 14]}}
  },
  "sheets": {
    "chr_guest_a_v1.png": {
      "cell": [48, 96], "anchor": [24, 94], "fps": 8,
      "actions": {"walk_down": {"row": 0, "frames": 4}, "walk_up": {"row": 1, "frames": 4},
                  "walk_left": {"row": 2, "frames": 4}, "walk_right": {"row": 3, "frames": 4},
                  "sit_eat": {"row": 4, "frames": 2}, "toast": {"row": 5, "frames": 3}}
    }
  },
  "items": [
    {"id": "table_01", "kind": "table", "file": "blk_table_v1.png", "foot": [612, 420], "main": true},
    {"id": "lamp_L1", "kind": "prop", "file": "blk_lamp_v1.png", "foot": [440, 300]},
    {"id": "garland_arch", "kind": "decor", "file": "blk_arch_v1.png", "foot": [768, 236], "layer": "wall"},
    {"id": "guest_017", "kind": "person", "sheet": "chr_guest_a_v1.png", "action": "sit_eat",
     "table": "table_01", "seat": 3},
    {"id": "waiter_02", "kind": "person", "sheet": "chr_waiter_v1.png", "action": "walk_left", "foot": [355, 470]},
    {"id": "groom", "kind": "person", "role": "groom", "sheet": "chr_groom_v1.png", "action": "idle_down", "foot": [752, 285]}
  ]
}
```

- 坐着的人只写 `table` + `seat`，位置从桌子的 seats 算，不用再给 foot。给了也行，02 拿来互相核。
- `kind` 就这几种：`table`、`prop`（挡路的立件）、`decor`（不挡路：墙上的、地上的花瓣）、`person`。

## 02 怎么用

- 北边：照清单原样摆（01 定：摆位 A，人 84）。
  - 效果图里人如果不是 84，02 整张按 84 ÷ person_px 缩放。零件也跟着缩，**所以零件、动作图的比例要跟效果图一致，不要各自一个比例**。
- 往南：照 A 的排法（行距、列距各加约 35 留路，红毯至少两个人宽）排满 55 桌，用的是清单里同一种桌子、同一批人。
