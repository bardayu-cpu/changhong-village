## 一、做法

调试版日志面板顶上加了两个按钮「远程加载」「删掉本地副本」（点左上角绿字打开）。点「远程加载」：

1. 先看本机 `user://canvas/scene_roman_banquet/base.png` 有没有、大小对不对。有而且对，就直接读本地，**不下载**（第二次打开走这一路）
2. 没有：Godot 经云桥发一个 `@fetchFile` 给微信那一层（`wxgame/remote.js`），带上 File ID 和 `user://` 的绝对路径
3. 微信那一层：`wx.cloud.downloadFile` 下到临时文件 → `readFile` 读成 ArrayBuffer → `GODOTSDK.copy_to_fs(路径, 数据)` 写进 Godot 的文件系统。模板把 `/userfs`（就是 `user://`）挂成 WXMEMFS，写完关文件时同步写到微信本地文件，下次启动挂载时读回来
4. Godot 读出这个文件 → 解码 PNG → 传显卡 → 在面板上显示那张图，面板上写一行用时

每一步用时打进日志，都以「[suqi] 远程加载」开头：下载、读临时文件、写进 user://、桥来回、读本地、解码、传显卡、总共。本地副本大小不对或者解不开，就删掉重下。

名字以 `@` 开头的请求不去调云函数，交给微信那一层自己做（`cloud.js` 里加了这条转发）。只往显卡传图，不从显卡读回。

## 十、第 30 版真机：下不下来，改走云函数（9/19，提交 f70d681）

### 真机结果和原因

- 第 30 版（0919-0822）真机点「远程加载」出「下载失败：download_failed internal server error: empty download url」；心跳、存资料、小游戏都正常（01 转）
- 原因（阿鱼查实）：云开发控制台 → 存储 → 权限设置是「仅创建者可读写」。那页写着云控制台和服务端始终有所有文件的读写权限，这个设置只管小程序端发起的请求。所以阿鱼在控制台传的图，玩家读不到，`wx.cloud.downloadFile` 就回 empty download url
- 改权限要升级付费版，阿鱼暂不升级

### 「empty download url」还可能是什么（以后再遇到照这个查）

1. File ID 和控制台里的对不上：复制时少了字、多了空格或换行、路径大小写不对
2. File ID 里的环境和游戏 init 的环境不是同一个（换过环境、复制了别的环境的 File ID）
3. 文件被删了、挪了位置，或者重新传过换了 File ID
4. 存储用了自定义安全规则，规则不让读
5. 环境欠费、停用，或者流量超了【待验证：这几种会不会也报这一句】

这次别的都排除了：环境对得上（File ID 和 `wxgame/cloud.js` 都是 cloud1-d9ggg36tj34742bef），别的云函数都通，03 核过 File ID（第九节）。

### 加了诊断（小程序自己下那条路失败时）

- `wxgame/remote.js`：`wx.cloud.downloadFile` 失败，或者成功了却没有临时文件，就顺手问一次 `wx.cloud.getTempFileURL`，带回：
  - 它回的 status、errMsg
  - File ID 里写的环境、游戏 init 的环境
  - File ID 多长、有没有空白换行
  - 开发版、体验版还是正式版
- `scripts/remote_probe.gd` 翻成一句人话，日志和调试面板上都有，截图就看得出是哪种：
  - 没权限（STORAGE_EXCEED_AUTHORITY）
  - 文件不在（STORAGE_FILE_NONEXIST）
  - 两边的环境对不上
  - 临时链接拿得到（那就是下载那一步的事）
- 临时链接 8 秒不回也照样把下载失败交回去，不会卡住

### 几条路比一比

| 路 | 要配下载域名吗 | 免费版能用吗 | 一次多大 | 开发版、体验版、正式版 | 结论 |
