## 一、做法

调试版日志面板顶上加了两个按钮「远程加载」「删掉本地副本」（点左上角绿字打开）。点「远程加载」：

1. 先看本机 `user://canvas/scene_roman_banquet/base.png` 有没有、大小对不对。有而且对，就直接读本地，**不下载**（第二次打开走这一路）
2. 没有：Godot 经云桥发一个 `@fetchFile` 给微信那一层（`wxgame/remote.js`），带上 File ID 和 `user://` 的绝对路径
3. 微信那一层：`wx.cloud.downloadFile` 下到临时文件 → `readFile` 读成 ArrayBuffer → `GODOTSDK.copy_to_fs(路径, 数据)` 写进 Godot 的文件系统。模板把 `/userfs`（就是 `user://`）挂成 WXMEMFS，写完关文件时同步写到微信本地文件，下次启动挂载时读回来
4. Godot 读出这个文件 → 解码 PNG → 传显卡 → 在面板上显示那张图，面板上写一行用时

每一步用时打进日志，都以「[suqi] 远程加载」开头：下载、读临时文件、写进 user://、桥来回、读本地、解码、传显卡、总共。本地副本大小不对或者解不开，就删掉重下。

名字以 `@` 开头的请求不去调云函数，交给微信那一层自己做（`cloud.js` 里加了这条转发）。只往显卡传图，不从显卡读回。

## 三、手机上怎么验（阿鱼）

1. 扫调试版码，进到宴会厅
2. 点左上角绿字打开日志面板 → 点「远程加载」→ 等几秒。面板上应出现宴会厅那张图，上面一行写「下载 … 毫秒，解码 … 毫秒，…（这次下载了）」→ **截图**
3. 彻底关掉小游戏（右上角「…」→「重新进入小程序」，或者在微信里把它划掉），再打开 → 进宴会厅 → 打开日志面板 → 点「远程加载」。这次应写「读本地 … 毫秒 …（读的本地，没下载）」→ **截图**
4. 哪一步不对：把日志面板往下翻到「[suqi] 远程加载」那几行，截图发回来
5. （可选）点「删掉本地副本」再点「远程加载」，又会走下载那一路，可以多量几次下载要多久

回报两张截图就够：用时那一行、图出没出来、第二次是不是「读的本地，没下载」。

## 六、还没验证的

- **最要紧**：真机上 `GODOTSDK.copy_to_fs` 调不调得通、写完 Godot 马上看不看得到（纸面上是通的）
- 真机上 `user://` 是不是 `/userfs`：日志第一行「开始 本地 … → …」会把绝对路径打出来
- 关掉小游戏再开，本地副本还在不在（WXMEMFS 同步落盘）
- 2.2 MB 下载要多久；手机上解码要多久、卡不卡帧（左上角「最慢 … 毫秒」、日志里「卡了 … 毫秒」）
- PNG 以外的格式（JPG、WebP）能不能解：这次只验 PNG；代码按扩展名挑解码器，换格式只改清单
- 微信本地文件空间上限，占满了会怎样
- 安卓机

## 七、9/19 的一次失误（已按 01 的意思处理）

验证导出脚本时，我在临时目录建了一个指向 godot 的符号链接去跑原脚本，脚本里的 `rm -rf ../wechat-build` 按真实路径走，把真的 `wechat-build`（第 28 版 0919-0246 的导出）删了，换成了当时工作区的导出。01 定：不还原（第 28 版的码阿鱼已经扫过，在微信服务器上有效，现在不需要上传），下次出码从最新提交重导，会盖掉这个目录；也不拿旧版本号 0919-0246 标别的导出（会把版本弄混）。之后导出脚本加了输出目录参数：只想验证脚本时给一个临时目录，里面有东西又不像上次导出的就不删。往 `wechat-build` 导出、出预览码仍然只归 01。
