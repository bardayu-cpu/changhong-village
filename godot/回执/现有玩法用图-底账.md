## 6、尺寸汇总（GPT 按这个出，接进来不用缩放）

| 类 | 交付尺寸 | 依据 |
| --- | --- | --- |
| **菜牌 / 纹样 / 作物阶梯** | **128×128** | 已验收的 12 张就是这个尺寸。屏幕上最大用到 112（小菜合大菜），128 够用不糊 |
| **游戏里的道具**（糖、红包、炮） | **建议 128×128，和菜牌一套** | 现在屏幕上是 40×40，但同一套里统一尺寸最省事 |
| **夹菜的盘子** | **130×130** | 代码里写死的上限，一直是这个数 |
| **接彩头的篮子** | **100×54**（篮身 100×40 + 提手 14） | 现在代码画的尺寸；要加角色抱着的话这个框得重定 |
| **人物图集** | **一格 48×64，一行 16 格**（下 0–3、左 4–7、右 8–11、上 12–15），透明底，同名 json 给 `frame`/`frames`/`fps`/`height_m` | `ASSETS.md` 第 3 节；`chr_guest03` 已按这个交过 |
| **厅里人的显示高度** | **84 像素** | `scene.json` 的 `person_px` |
| **场景底图** | **1536×1024**（湖边、果园是 1536×1280） | 六块画布的定稿尺寸 |
| **场景积木** | 原尺寸即用，脚点写进交接单 | 现有的：圆桌 165×148、栏杆 433×261、灯笼 31×67、花盆 46×72 |
| **氛围小件** | 10～230 像素不等，见第 3 节 | 现在全是占位，换正式图按同名同尺寸即可 |
