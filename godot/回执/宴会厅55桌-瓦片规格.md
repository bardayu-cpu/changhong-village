## 先说一个量出来的问题

**现在这张底图是带透视的**，和 ASSETS A04「斜俯视正交、没有透视」对不上。所以只在中间补一截接不上，量下来：

| | 实测 |
| --- | --- |
| 地砖竖缝 | 是斜的，越往两边越往外撇 |
| 地砖小花 | 左右间距从中间 70 到两边 86 不等 |
| 地砖行距 | 越往下越大，上面 50，下面 60 |
| 红毯 | 越往下越宽，y 320 宽 114，y 700 宽 153（红的那段） |
| 两边墙 | 斜着往里收，左墙到 y 540 就没了 |

**所以瓦片按正交画，拼法这样定**（02 负责拼）：
- **地面、红毯**：整个厅的地面和红毯都用瓦片重新铺，不只铺中间那截。原底图的透视地面、透视红毯全部盖掉
- **原底图里不是地面的东西**：北墙、婚礼台、两边墙的上半截、下面的栏杆、大门、东侧门，由 02 从原底图抠成积木，盖在瓦片上面，原样用
- **两边墙**：原底图的墙到 y 540 左右就收住了，从那儿往下到栏杆、东侧门，用侧墙段竖着接下去

## 一、地砖

| 项 | 要求 |
| --- | --- |
| 文件 | `tex_banquet_floor_v1.png`，放 `001-宴会厅/积木/` |
| 尺寸 | **80×52**（一块地砖约 1.7 米 × 1.6 米，照现在厅中间那一带的地砖大小取的整数；一个美术像素 = 2×2 画布像素，所以都是双数） |
| 图案 | 和现在底图的地砖一样：米色砖面，细细的浅褐砖缝，砖缝十字交叉处一朵橘色四瓣小花（现在的小花约 16×12） |
| 砖缝位置 | 砖缝横竖各一道，**从瓦片正中间穿过**，小花在正中间。瓦片的四条边是砖面，不是砖缝，这样拼的时候边上不会出双线 |
| 颜色 | 照底图取的：砖面 `#f0c89c`～`#f0cca0`，小花 `#e89850`、`#e09048`，砖缝比砖面深一点（约 `#e8b888`） |
| 不许 | 透视（砖缝必须横平竖直）、明暗渐变或暗角（一块亮一块暗，铺开就是一格一格的）、透明像素、字 |

## 二、红毯

| 项 | 要求 |
| --- | --- |
| 文件 | `tex_banquet_carpet_v1.png`，放 `001-宴会厅/积木/` |
| 尺寸 | **宽 140、高 96**（红毯约 2.9 米宽，照现在厅中间 y 560 那一行量的：外沿 679～816，宽 138，取双数 140） |
| 横着分三段 | 左边金边回纹带 **18** / 中间红 **104** / 右边金边回纹带 **18** |
| 颜色 | 中间红 `#bc302c` 上下；金边照现在的橘金 `#f88434` 加深红底 |
| 上下怎么接 | 竖着一段一段往下铺，**接缝在瓦片的上边和下边**。回纹一格高 **24**，96 高正好 4 格，上边第一格和下边最后一格要接得上，看起来是一条不断的回纹 |
| 不许 | 越往下越宽（两条边都要竖直）、红毯中间的花纹大到能看出一段一段（中间红最好是细密的暗纹或者纯色） |

## 三、侧墙

**左边那条重复的帘子，是左墙的一部分，不是单独的东西。** 原底图 y 352～454 那一段左墙上挂着红帘子；02 拼占位时把那一段竖着重复铺，就成了一串帘子。正式的侧墙段里可以有帘子（两段里一段带帘子就够），不单独交。

| 项 | 要求 |
| --- | --- |
| 文件 | `tex_banquet_wall_left_v1.png`、`tex_banquet_wall_right_v1.png`，放 `001-宴会厅/积木/` |
| 尺寸 | 各 **宽 96、高 240**（96 = 现在右墙上半截从柱子到画布边的宽，约 2 米；240 = 一个开间：一根柱子加一段墙板，约 5 米） |
| 画法 | 正交，墙竖直往下走，不往里收；一段里有一根木柱、一段木墙板；挂的灯笼照比例尺（挂着的灯笼高 19～24，ASSETS 第 15 节；现在底图上的壁灯画大了）。光从左上来：左墙朝厅那面偏暗，右墙朝厅那面亮一点 |
| 朝厅那一边 | 左墙的右边沿、右墙的左边沿是墙脚，贴着地砖；**墙脚要竖直**，可以带一道 2 像素的墙脚线 |
| 上下怎么接 | 竖着一段一段往下铺，接缝在上边和下边，**接缝不许落在柱子正中间**（柱子要整根在一段里），上边一行和下边一行要接得上 |
| 透明 | 朝画布外那一边（左墙的左边、右墙的右边）可以不透明；朝厅那边墙脚以外必须透明，露出下面的地砖 |
| 不许 | 往里收的透视、门窗（东侧门用原底图的）、字 |

## 四、怎么验（交回来 02 照这个验）

1. **硬规格**：尺寸、有没有透明、sha 对交接单。地砖、红毯不许有透明，侧墙朝厅那边透明
2. **接缝差**：跑 `python3 godot/tools/check_tile.py`
   - 地砖：`--size 80x52 --dir hv`
   - 红毯：`--size 140x96 --dir v`
   - 侧墙：`--size 96x240 --dir v --alpha-ok`
   - 瓦片首尾相接时挨着的那两行（上下）、两列（左右），平均差不超过 8/255 算过。现在底图地砖上下接的差是 2.4～7，照这个量级
3. **拼起来看**：同一个工具加 `--out` 出两张图，一张是地砖拼 4×4、红毯和墙竖着接 6 段，另一张在接缝处画了细线。不看画线那张也能看出一格一格的，就是没过
4. **比例**：跑 `scale_check.py`，照「人 = 1」表量：地砖一块 80×52（约 1.7 米见方）、红毯宽 140、墙上灯笼高 19～24
5. **进游戏看**：02 铺进 55 桌大厅，手机 540×960 截图，看三处：
   - 大门口
   - 厅中间
   - 婚礼台前（瓦片和原底图上半截接的地方）

   看有没有接缝、有没有一格一格的明暗，墙和上半截原墙接得顺不顺

工具在 `godot/tools/check_tile.py`。拿现在底图切一块地砖试过：上下接缝差 2.4，过；从透视红毯上切的一段是 9.9，不过。
