## 每张用在哪

| 图 | 用在哪 |
|---|---|
| `base_ui_frame_v1`（540×960，九宫格 24，中间透明） | 整屏外框，盖在最上面、不挡点；底子垫深酒红（照预览图），面板往里收到框里面（离边 28），字和按钮不压金边 |

| `prop_ui_coin_v2` | 「N 金」左边，48 原大 |

| `base_ui_card_v1` | 开始卡、结算卡、「歇一下」卡的底：米色纸，九宫格照卡上的花留边（左右 48、上下 90），字改深色（标题酒红、正文墨色），从上下两道花边里面写起 |

| `base_ui_btn_sub_v1` / `_pressed` | 其余按钮（离开、歇一下、菜单册、调试那排），字深色；两头有菱形花，字左右各让 22 |
| `base_ui_board_v1`（九宫格 16） | 三个游戏的棋盘底（连连看比牌大一圈，外圈连线也在底上） |
| `base_ui_cell_v1` | 每一格的底（空格看得见，小菜合大菜、消消乐最明显） |
| `decal_ui_select_v1` | 选中那张牌盖一个金框（比牌大 144:128），代替原来染金描边 |
| `decal_ui_matched_v1` | 连连看配对消掉、消消乐消掉、小菜合大菜合成那一下，在那格冒一个星星，0.35 秒淡掉 |
| `tex_ui_link_v1` | 连连看的连线换成这一截金条一段段铺 |
| `prop_ui_coin_v1` | 不用（01 定用 v2），文件留着 |
