# 组件库罗-1：界面颜色、字号收到一处（庄Z2，10/5）

> 庄Z1 派（组件库 v0.1 `docs/组件库-v0.1.md` 9d5a22c 第二节第 1、2 条 + 第三节罗-1）。阿鱼：「会有一些公用的组件库来确保整个游戏画面的统一」。
> 底线：这一步画面一点不变，只是把颜色、字号收到一处。分支 `ui-kit-1`（新模块「公共·界面组件」，前缀 ui-kit），从 main 93747d8 开。不合 main、不出码、不推。

## 一、做了什么

- 先把 tests-1005（b6b60e8）合进 main：**93747d8**（主仓库里别的窗口没提交的文件不碰，合并只动那 5 个文件）。
- 新建共用文件 **`godot/scripts/ui/ui_kit.gd`**（以后裳泓村也从这里取）。用法：`const UI = preload("res://scripts/ui/ui_kit.gd")`。里面分四节：
  1. **新皮**（定稿图那套）：深褐底 BG、最外线 EDGE、金棕线 LINE、米白字 TEXT、名字黄 NAME、喜红那一组（RED、RED_DARK、RED_DOWN_BAND、RED_EDGE、RED_RIM）、金钉 STUD_LIGHT／STUD／STUD_DARK、泡白那一组（BUBBLE_BG、BUBBLE_EDGE、BUBBLE_TEXT）。
  2. **字号**：SIZE_BODY 24、SIZE_TITLE 36、SIZE_BIG 48（另有 SIZE_TAG 12，只给不用读的角标数字）。
  3. **旧主题**：标「罗-2 换掉」，照原值放进来：OLD_GOLD `#d4af37`、OLD_GOLD1、OLD_PAPER、OLD_MUTED、OLD_ERR、深紫面板底 OLD_PANEL、顶栏小牌 OLD_CHIP、按钮按下／不能点、输入框底、小游戏酒红遮罩和菜单册几色……
  4. **遮罩、过场、调试**：DIM 一组压暗、SWITCH_TINT、DEBUG_TEXT 等。
- **改成从这个文件取的**：
  - `main.gd`、`banquet_ui.gd`、`court_ui.gd`、`arrival_card.gd`、`games/game_host.gd`：
    - 各自开头抄的那组颜色常量（GOLD、GOLD1、PAPER、MUTED……）**名字照旧**，值改成 `UI.OLD_*`。名字照旧是因为 `lounge_ui.gd`、`drive_in.gd`、`estate_map.gd` 用着 `m.GOLD`、`m.PAPER` 这些名字，一个不用改。
    - 代码里散写的界面颜色（面板底、遮罩、错误红、调试绿、按钮按下／不能点、输入框底、字阴影、摇杆圈、结算卡底、菜单册纸和字……）都换成 `UI.*`。
  - `ui/dialog_skin.gd`：PAL 那张表的色号字符串换成 `UI.*`。读颜色的 `_c()`、`_rim()` 改成认颜色对象（也认字符串）。`title_screen.gd` 里读 `Skin.PAL` 外面本来就包着 `Color(...)`，不用改。
- **这几个文件里还写死的颜色都是场景里的东西，不算界面**：`court_ui.gd` 的相纸底 `#f4f1ea`、合影小图（草地、合影地毯、花、喜字底和喜字）、爱心贴纸、海报纸和海报上的字。照组件库第二节「不并进来的：信纸相纸这类物件、场景里的东西」。
- 字号这一步只在共用文件里定好三档，各脚本里写的 24、26、30、22……**没改**（改了画面就变了）；挪到 12 的整倍是罗-7。
- 另加一个验收小工具 `godot/tools/dump_ui_colors.gd`：开游戏、各块画布都搭起来，把界面上每个节点的颜色、字号、框样式（像素框按图内容算指纹）、色块颜色倒成一份按路径排好的清单。改前改后各倒一份逐行比；以后罗-2～8 也用它看「改了哪些、没改哪些」。

## 二、验收

### 1. 画面没变

- **颜色清单**（`tools/dump_ui_colors.gd`，headless）：改前倒两份，一模一样（2259 行），清单本身是稳的；改后倒一份，**跟改前一行不差**。对话框那几个像素框、名字牌、选项按钮的图逐字节一样。
  - 只记界面节点：场景里一闪一闪的标记透明度一直在变，不记。
- **截图**（540×960）：宴会厅、迎宾院、后厅走廊、休息室、全景地图（5 张）、对话框（第一句、第二句、选项、身份卡 4 张）。
  - 同一版代码拍两遍本身就对不上：人在走、在呼吸、冒泡在换，对话框那几张后面的场景每次停的位置都不一样，差几千到三十万像素。所以逐像素硬比没有意义。
  - 做法：改前拍两遍，两遍一模一样的像素算「稳定像素」（界面框、按钮、字基本都在里头），改后拍一遍，只要稳定像素里有一个变了就是颜色真变了。
  - 结果见下面第 4 节。
- 截图里地图、对话框那两套工具不会自己建文件夹，第一次存不下来；拍之前先建好文件夹再拍。对话框截图工具做到第 6 张「迎宾院新娘妈妈」时停了：老问题，改前也一样，不是这次带出来的。

### 2. grep

六个文件里查写死的颜色（`Color("#…")`、`Color(r, g, b[, a])`），剩下的只有迎宾院那几样东西（上面列了）。另外两种写法不算写死：
- `Color(0, 0, 0, 0)`：全透明；
- `Color(GOLD1, 0.9)` 这种：从共用文件的颜色派生的透明度。

见第 4 节。独立 HOME、TMPDIR 跑。

## 三、风险

- `lounge_ui.gd`（身份卡框）、`drive_in.gd`（跳过开车提示）、`estate_map.gd`（全景地图面板、确认框）、`title_screen.gd`（开场页）、`layered_hall.gd`（门牌）、`entrance.gd`（路牌）里**也写死着旧主题颜色**，不在罗-1 的名单里，没动。它们分别是罗-4、罗-5、罗-2、罗-8 那几件要换的，换的时候一起改成从 `ui_kit.gd` 取。
- 共用文件里「旧主题」一节比组件库文档列的多：把五个文件里散写的面板底、遮罩、调试色都收进来了，不然 grep 过不了。罗-2 换新皮时这一节整段删。
