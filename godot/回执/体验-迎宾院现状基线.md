# 体验 · 迎宾院现状基线（04，10/2）

看的提交 **a1faf93**（main 最新，第 55 版那套）。540×960。用 `capture.sh` 的 `court_*`、`title`、`nick`、`avatar` 预设一路截下来（共 28 张，挑 8 张进了仓库），不用 `shot.sh`（它只截宴会厅）。对照 `docs/迎宾院-玩家说明-v1.md`。**只看现状，没改任何东西。**

**给阿鱼的一页**（下面的「你」都是来吃席的客人）

**一句话**：**这一路现在是通的，也顺：进门有箭头指路，新娘妈妈一句一句告诉你下一步，没签到进不去楼门。但院子是空的、不动的，而且你要的三样（祝福、海报、走动的人）现在一样都没有。**

**现在走得顺的**：
- 进门第一屏有个金色箭头指着签到桌，新娘妈妈说「来啦，先到这边签个到」，你不会不知道干嘛。
- 签到三步（名字 → 礼金 → 确认），每一步一屏、按钮都够大，礼金可以选「不送」。签完说「喜糖收好了」，新娘妈妈再告诉你：「回忆册可以先翻翻，翻完去花墙拍张照，里面已经开席了」，**下一步都交代了。**
- 没签到就想进楼门，新娘妈妈拦你说「先签个到」。
- 合影：选「站好／招手／比心」→ 对圈 → 相纸，「再拍一张」「收好」两个键够大。

**跟你要的比，现在缺的**：
1. **没有祝福。** 签到只有名字和礼金，没有那句公开的祝福。
2. **没有海报。** 相纸出来只有「再拍一张」「收好」，没有「做成海报」。
3. **院子里的人一个都不走。** 一共五位（新娘爸妈、两位摄影师、休息区一位老人）加花墙上的新人，全站着不动，只有轻轻的呼吸起伏，没有别的客人。你要的「人来人往」现在是一个空院子。
4. **回忆册认不出来。** 签到桌旁边就是一个棕色小方块，不像本书，点了说「还没印好」。（内容要等阿鱼写，这个不算毛病，认不出来才是。）

**还有两处顺手要说**：
- **院子是灰色方块搭的，跟宴会厅的画差很远。** 你选完形象第一眼看到的就是这个，前一屏标题页后面还是漂亮的宴会厅，掉差很大。
- **默认的形象放大看是糊的、带红黄杂点。** 新人打开游戏默认选第 3 个，也是 8 个里唯一的 GPT 画的人；放大看全身是红黄色的小杂点，像坏掉了，别的 7 个是干净的老画法。**这是你自己在每个场景里都会看见的小人。**

## 六、照说明改的时候必须做的 5 条

1. **签到最多四屏，祝福那屏可以跳过，别打字也能签。** 现在名字 → 礼金 → 确认是三屏，加祝福变四屏（名字／礼金／祝福／确认）。长辈打字难，给三四句现成祝福一点就用，再留一个「自己写」；过敏感词时显示「换个说法吧」，不丢掉前面填好的名字和礼金。
2. **走动的人不能挡路，也不能挡着关键的地方。** 划出四块「不许站、不许走过」的地方：红毯中间、签到桌前一格、花墙前合影的位置、回忆册前一格。走动的人数先少后多，建议先放 6～8 个；走到玩家跟前要让开，不能把玩家卡在角落。每加一批，我拿 540×960 截图看有没有压住按钮、牌子、箭头。
3. **保住现在好用的引导，一样也别丢。** 进门的金箭头、新娘妈妈三句话（签到前、签到后、出门）、没签到拦楼门。新加祝福和海报以后，新娘妈妈签到后那句要改成能带上它们（比如「签好了，去翻回忆册、花墙拍张照」），仍然是一步一句。
4. **回忆册要认得出是本书，海报键要够大。** 入口画成书或立块牌，走近之前就看得出；相纸页「做成海报」「再拍一张」「收好」三个键各宽 ≥140、高 ≥55，海报预览里的字实际 ≥20 像素，别让小程序码和字压在新人身上。
5. **灰盒换画之前，每一版先量比例。** 签到桌、树、门、花墙对「人 = 1」的比例尺量一遍再接图（现在签到桌 2 个人宽，树 1.8 个人高，都偏）；同时把默认形象换成干净的，因为人动起来以后，每个人的小人都要靠它撑画面。
