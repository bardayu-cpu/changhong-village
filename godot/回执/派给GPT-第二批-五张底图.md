# 二、格式（这部分是我定的，请照这个交）

| 类 | 要求 |
| --- | --- |
| **格式** | PNG，透明底，**alpha 只有 0 和 255**（不要半透明边、不要棋盘格假透明） |
| **可重复接的颗粒** | 接缝要能无缝拼（左右接的上下无所谓，上下接的左右无所谓），交接单里写明**往哪个方向能接** |
| **能挡住人的颗粒** | 交接单里写明这是**能挡人的**（我会做成积木或前景层） |
| **锚点** | 立在地上的东西给**脚点**（这件东西"站在地上"的那一点，写成图片内部的像素坐标） |
| **原尺寸即用** | 图多大我就按多大摆，不放大缩小。尺寸你定，写在交接单里 |
| **命名** | 全小写、下划线分隔、不用中文和空格。底座和瓦片 `tex_*`、能挡人的积木 `blk_*`、挡在人前面的 `fg_*`、小道具 `prop_*`、装饰 `decal_*`。这批统一 `_v1`，不覆盖已有文件，改版加 `_v2`。两块画布同一种东西画法不同时名字里加场景词（`tex_grass_lawn_v1` / `tex_grass_orchard_v1`） |

**交接单**：每块画布一份，放该画布 `交接/`，叫 `handoff_<场景 id>_blocks_v1.json`（例 `handoff_scene_luoman_lake_blocks_v1.json`）。格式照第一批那份 `handoff_minigames_shared_dish_tiles_v1.json`，每个文件写：路径、尺寸、sha256、**能不能重复接（往哪个方向）**、**能不能挡人**、**锚点（脚点）**。

**还要一样：拼好以后的效果图。** 阿鱼说他会本人确认那张图——**那就是标准答案**，我拼完拿它比对，对不上就是我拼错了。一块画布一张，放该画布的 `素材图/`，交接单里指明是哪个文件。

**最要紧的一样：拼接方式。** 交接单里要写清楚**这些颗粒怎么拼成那块画布**——哪块底座铺哪片区域、哪个颗粒重复几次摆在哪、哪些压在哪些上面。我按你写的拼，拼错了是我的问题，没写清楚是你的问题。
