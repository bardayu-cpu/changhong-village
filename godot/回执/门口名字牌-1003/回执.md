# 后厅三间门口挂名字牌、宴会厅东侧门挂「后厅」· 02 E，10/3

分支 `room-signs`，从 main（99cb659）开。没合、没推。小改动不过 04，01 F 看截图。

阿鱼原话：「对了每个房间的门口需要用牌子写明这是哪里」。画风页第 0 节 10/3 晚已写进「房间门口可以挂写房间名的牌子」（2acbc4d），跟「有图的牌不叠字」不打架。

## 看哪几张
- `手机-走廊-化妆间和休息间.png`、`手机-走廊-休息间和麻将室.png`：540×960，人站在走廊上（新预设 `backhall_signs_w`、`backhall_signs_e`）。手机一屏 540 宽，三个门口从西到东隔了 750 多，一屏装不下三块，所以分两张。

## 做了什么
- **牌子的样子**：红底、金字、细金边的小匾，字用游戏字体 22 号（世界里的字是 18，大一号，长辈看得清）。
  - 跟出口那种暖褐小木牌（「回宴会厅」「回草坪」）分开：木牌是「去哪」，红匾是「这是哪」；红金跟两间房、宴会厅的喜庆一个调子。
  - 牌子是游戏里画的，没改像素画的底图。
- **后厅三间**：化妆间、休息间、麻将室，各挂在门洞东边的前沿矮墙上，离门洞 10 像素，下沿在墙上（695）。
  - 不压门洞，不加挡人的占地，走廊从西到东照样走得通。
  - 按墙脚那条线排前后：走廊里的人走过去画在牌子前面。
  - 位置写在后厅 layout 的 `signs` 里（改位置只改 json）。
  - 麻将室还是灰盒，牌子先照门口位置挂上了。
- **宴会厅东侧门**：04 报的「东墙最南边那扇通后厅的门没有任何牌子、箭头」（`体验-第一次来整条路.md` 第三节 1）**现在还没有牌子**。
  - 现在有的只是第一次坐下以后才出、进过后厅就收的金光圈和屏幕边箭头。
  - 所以照同一种匾挂了一块「后厅」，在门板上方、贴着东墙，不压门那个点。
  - 宴会厅的 scene.json 是脚本生成的、不手改，这块牌子跟着厅里的东侧门那个点（side_door）走，不写进 json。
- 原来的截图预设 `hall_side_door` 用的是第 44 版厅的坐标 (1440, 600)，在 55 桌厅里镜头不在东侧门，所以另加了 `hall_backhall_sign`。老预设没动。
