## 要什么，每样在玩法里干什么

| 元素 | 在玩法里干什么 |
| --- | --- |
| **钢琴 + 琴手** | 现在纯氛围，不能点。**但以后要做「给乐队点一支曲」**——玩家花金币点一支，当场换曲、全厅都听见。所以这四个人**要看得出正在演奏**，而且要能表现出"换了一支曲"（比如飘的音符换个样子、动作换一下） |
| **大提琴 + 琴手** | 同上 |
| **小提琴 + 琴手 ×2** | 同上。两个人，可以是同一块图摆两次，也可以画成两个人，你定 |
| **飘的音符** | 从乐队头上慢慢往上飘。**要单独一小块图**（引擎负责让它动、换样子），别画死在乐手身上 |
| **舞台上的灯／灯笼的光** | 一闪一闪，纯氛围。**光要单独一块**（引擎做闪的效果） |
| **乐队脚下那块台面／地毯** | 让人看出"这一块是乐队的地盘" |
