# 截图环境 · 用法（02，10/2；00 批、01 E 派）

**一句话**：`zsh godot/tools/shot.sh <提交> --out=图.png [参数]`。从干净状态一条命令就能出图：
1. 把固定的截图 worktree（`.claude/worktrees/shot`）切到这个提交；
2. 这个提交没导入过就跑导入，导完核一遍；
3. 截一张。

**导入不全直接报错退出，不出图**，免得拿空厅、灰底的截图去比。

## 常用

```
# 北边那块 1:1，不放人、没界面（以前 03 打 render_north_1to1.patch 出的那张）
zsh godot/tools/shot.sh HEAD --out=/tmp/北边.png

# 整厅缩成 1/4、不放人
zsh godot/tools/shot.sh HEAD --out=/tmp/整厅.png --rect=0,0,1536,3440 --zoom=0.25

# 某一块带人、带界面（手机屏那样）、开席时间
zsh godot/tools/shot.sh HEAD --out=/tmp/中间.png --rect=0,1200,1536,1024 --people=1 --ui=1 --feast=feast

# 只准备环境（切提交、导入、核），不截
zsh godot/tools/shot.sh HEAD --prepare-only
```

| 参数 | 默认 | 意思 |
| --- | --- | --- |
| `--rect=x,y,w,h` | `0,0,1536,1024` | 画布上哪一块，整厅坐标；默认就是北边那块 |
| `--zoom=` | `1` | 出图大小 = w×zoom、h×zoom；1 就是一比一 |
| `--people=` | `0` | 0 不放人：宾客、亲友、服务员、新人、自己、桌上的菜和牌都藏。1 照常 |
| `--ui=` | `0` | 0 只存厅那块，没界面；1 存整个手机屏（540×960、带界面），镜头对着 rect 中心 |
| `--hall=` | `55` | 55 = 55 桌大厅；44 = 第 44 版 12 桌厅 |
| `--feast=` | 空 | 空照北京时间；`feast` 强制开席；`pre` 强制开席前。只有 `--people=1` 看得出 |

- 成功最后一行：`SHOT SAVED <路径> <宽>x<高>`，退出码 0。
- 失败：`SHOT FAILED <原因>`。退出码 2 是环境、导入的问题；1 是截图本身的问题；64 是参数不对。

## 它怎么保证「导入跑完了」

- **什么时候导入**：只有这个提交第一次用、或者上回没导完，才导入（`Godot --headless --editor --quit-after 600`）。
- **导完核三样**，有一样不对就报错退出：
  1. 日志里没有 `Scan thread aborted`；
  2. 每张图、每个字体、每个声音（有 `.gdignore` 的文件夹不算）都有 `.import`；
  3. 每个 `.import` 指的导入结果都真在 `.godot/imported/` 里。
- **核过才算准备好**：核过才在 `.godot/shot_ready` 里记下这个提交，下次同一个提交直接截，不重导。
- **换提交前先清干净**：先 `reset --hard`、`clean -fd` 清掉 worktree 里的改动，导入缓存（`.godot/`）留着，换回来快。

## 注意

- **截图脚本** `tools/shot_canvas.gd` **不改 main.gd**：像测试那样把游戏起起来，照 `big_*` 截图预设那条路进 55 桌厅，藏人藏界面（用游戏自己的 `_hide_people_for_shot`），再把厅那块子画面设成要的大小、镜头对准。
- **老提交也能截**：`shot.sh` 每次把这份仓库里最新的 `shot_canvas.gd` 拷进 worktree。只要那个提交的 main.gd 有这几个入口就行：`_set_hall_variant`、`_enter_banquet`、`_hide_people_for_shot`，9/30 以后的都有。
- **窗口**：截图要开一个 Godot 窗口，会闪一下；不能 headless，headless 不出画面。
- **撞车**：03、04 同时用会共用同一个 worktree，**一次一个人用**。
- **以前那个补丁**：03 的 `render_north_1to1.patch` 用不着了，北边 1:1 用默认参数就是那张（10/2 逐像素核过，见 `godot/回执/截图环境-回执.md`）。
- **测「导入不全会报错」**：环境变量 `SUQI_GODOT` 可以把 Godot 换成假的。
