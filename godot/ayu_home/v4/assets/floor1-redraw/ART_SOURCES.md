# 1005 一楼与小游戏画稿来源

本轮使用内置 `image_gen`，没有调用 CLI/API，也没有外部素材库。

- 布局：用户新定稿 `5-阿鱼家一楼平面图 3.png`。
- 画风：工程原有 `v3/assets/approved-2.png`，文件未改。
- 一楼原始生成稿：`floor1-generated.png`；最终运行图：`floor1.png`。
- 茶、汤、洗衣、木鸟、花纹桌、白天/夜空：`sources/` 内保存生成原稿。
- 插花桌面沿用原有 `life-scenes.png` 的木桌构图，重新按粗像素网格采样；花头、枝叶、花瓶新画。
- 种树/摘果保留原果园背景，只替换土块、篮子、果子。原来已经完整的钓鱼/喂鱼画面不动。
- `household`、`botanical`、`meals` 三张透明图集共 48 项；另有次净衣柜一项。各单项透明轮廓已拆出，没有米色底框。
- `sources/prompts.json` 留存提示词集及最后接入时的粗颗粒参数。
- `pack_redraw_art.py` 负责透明图集切分与最近邻像素采样；`build_floor1_redraw.py` 负责新图坐标、前景提取和一楼数据。

红线：麻将桌保持空桌面；花纹配对是植物图案，不是真牌；无真照片、无身体绘图。
