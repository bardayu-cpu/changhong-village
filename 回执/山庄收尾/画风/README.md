# R1 画风底子交付

本批是原创、手工编排的像素网格底稿：`source/draw_r1.py` 将每个 2×2 画布像素当作一个色块，全部用整数像素块绘制，最后以最近邻 2 倍导出，没有生成图、插值或渐变。色板 49 色（含画布底色），少于 64 色。材质是 16×16 美术像素、导出 32×32 画布像素；人物每张 32×42 美术像素，导出 64×84 画布像素。透明图仅采用像素边缘，脚底基线为 y=83，接触影往右下。

## 内容

- `主色板.png`：共用主色板色块。
- 九张独立材质：草地、柏油、石板、木头、白墙灰瓦、水、车漆、布、金属玻璃；`材质样.png` 是九材质并列样。
- `比例尺.png`：84px 人、100px 门、46px 椅、36px 桌、86×147px 车、树与门柱比较。图中形体按清单比例画出，二维示意并非场景拼装预览。
- `photographer_w.png`、`elder.png`、`farmer_2.png`：各一张 84px 站姿；按仓库身份线索分别保留摄影师肩带、老人银发眼镜、女性农夫长发肩带。三张为独立新画，不替换游戏图集。
- `car_mine.png`：独立北向小车 PNG，86×147 画布像素，右侧开门；透明留量处理奇数尺寸，不改变地面占地。

## 坐标、光向与落点

车的锁定地面 rect 是 `[461,873,547,1020]`，宽 86、高 147；画面保持北向，脚点对齐 rect 下边线 y=1020。PNG 高度为奇数，因此底边保留一行透明留量，禁止按偶数取整改 rect。材质的亮部在左上、暗部在右下；人物脚底基线一致，影子在脚右下。地面材质采用低对比，互动物件色彩更集中。

- 已逐张核对 PNG 尺寸和 RGBA 模式；三张人物均为 64×84，车为 86×147，材质各为 32×32。
- 主色板 49 色；材质单张 4–6 色，来自共用色组。
- 车的 rect 与高度记录来自 `全山庄重画-附表-逐件清单.md`；不对坐标做取整。
