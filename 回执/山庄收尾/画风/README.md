| Claude 退改项 | 新交付 |
| --- | --- |
| 1. 三个人物 | `photographer_w.png`、`elder.png`、`farmer_2.png`。独立 64×84 画布，人物实体 84px，不把脚影算入身高。用相机、拐杖/披肩、草帽区分职业，保留头部体积、分开的手和鞋、领口和衣褶。 |
| 2. 左上暖光 | 人物、车、树和各材质分别画出受光面、中间调和右下暗面。沿用原暖色系，主色板列出本次实际使用的 51 色；所有交付原稿的可见 RGB 都由源脚本核对。 |
| 3. 接触影与拖影 | `脚影.png`、`car_mine_shadow.png` 单独导出。贴地接触部分厚 2 个美术像素，右下淡影 alpha 77（约 30%），两层使用色板内暗色。 |
| 4. 车的 3/4 视角 | `car_mine.png` 北向原位，按不同斜面画前盖、车顶、车窗、近侧及朝南尾部，露前后轮，保留开门识别。外框 86×147，立高标注 71；奇数尺寸最后一行是透明锚边。比例尺使用同一张车图。 |
| 5. 九种材质 | 草地、柏油、石板、木头、白墙灰瓦、水、车漆、布、金属玻璃各 128×128，即 64×64 美术像素；源脚本按周期画跨边纹样。`材质样.png` 附 84px 人物，同板保留原尺寸。 |
| 6. 树 | `tree_scale.png` 独立 120×150，比例尺中与人物对齐同一脚线。树冠按错落叶团画出暖亮和背光区域，树冠间露枝，根干单独辨认。 |
