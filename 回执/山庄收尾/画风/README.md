比例尺仍为 560×448，公共脚线 y=230，人物高 84、门高 100、椅高 46、桌高 36、树高 150。保留 48 / 48 / 32 三轴和锁定车高 71 标注。车的停车占地和立高分开标注。

`R1-现有宴会厅对照.png` 是审图证据，展示游戏实际使用的宴会厅宾客及桌椅，并列新版 R1 人物和比例尺家具，分别用原尺寸和最近邻 2 倍。旧宴会厅图只在这张对照证据中出现，不参与新素材的色板和原创校验。

阿鱼家与宴会厅对色取自 `61c0500` 的正式素材。阿鱼家一楼餐桌 `floor1-redraw/dining-table.png` 的暖木、餐椅 `floor1-redraw/dining-chairs.png` 的奶油浅色，在 R1 用 `#896046`、`#b37b4e` 和 `#f0dfb8` 对齐。绿植 `floor1-redraw/botanical-4.png` 用来校树冠的暖绿方向，R1 保持 `#536d4e`、`#72885b`、`#93a36b` 三阶。正式 55 桌厅 `scene_roman_banquet_55/art_table.png` 的喜红与瓷白对应 R1 的 `#b44a3d`、`#d66d53` 和 `#f0dfb8`。这些都是已通过的 51 色里的颜色。

按 11/07 新安排，正式场景人物使用现有素材。本目录的人物图是历史内审对照，制作与验收停车场不依赖这些人物试稿。
