# R1 画风底子

源稿在 `source/draw_r1.py`，逐像素以整数块手绘，再按最近邻 2 倍导出。没有生成图、插值、渐变或素材拼贴。人物身体按 32×42 美术像素重新排画；脚影独立成 `脚影.png`。像素板文件透明处不计可见颜色，所有非透明 RGB 都从输出素材汇总进 `主色板.png`。

## 文件清单

- `主色板.png`：50 个实际使用颜色，不超过 64 色。色板方格按实际输出 RGB 排序；源稿 `P` 字典提供语义色名与色阶映射。每行八格，具体 RGB 与材质色阶如下。
- 独立材质：`草地.png`、`柏油.png`、`石板.png`、`木头.png`、`白墙灰瓦.png`、`水.png`、`车漆.png`、`布.png`、`金属玻璃.png`，各 32×32 画布像素。材质样板 `材质样.png` 按上述顺序从左至右排放，旁边有同稿 84px 摄影师作尺。
- `比例尺.png`：真实 84px 老人角色和真实尺寸的门、椅、圆桌、树、小车、门柱，同一脚点基线。比例板本身先按半分辨率美术网格绘制，再最近邻×2 导出。图内标注 1 米三轴标尺和每件尺寸。门宽以 44px 示意标记 43px 真值；车侧视约 72px，标注立高 71px，下方另有 86×147 地面占地示意。
- `photographer_w.png`、`elder.png`、`farmer_2.png`：各 64×84 画布像素、透明底，头顶 y=0，鞋底 y=83。对应肩带短发摄影师、银发眼镜老人、长发肩带女性农夫。没有把影子算入身高。
- `脚影.png`：独立脚影件；两颗深色接触影各为 2 个美术像素厚，右下拖影 alpha 约 30%。
- `car_mine.png`：北向红色小车，四个独立轮胎、前后灯、前后车窗、车漆左上暖亮、右侧压暗，右侧车门打开；无品牌和牌照字。车影另存 `car_mine_shadow.png`，透明度 30%，右下拖出。

## 色阶和光向

每种材质使用 3～5 级主体明暗。各组 RGB 色阶为：

- 草地：暗 `#536d4e` → 中 `#72885b` → 亮 `#93a36b` → 暖高光 `#c0b779`；花点 `#e1c779`。
- 柏油：暗 `#424b50` → 中 `#5e686b` → 亮 `#78817e` → 暖高光 `#9b9c8d`；裂缝 `#39454a`。
- 石板：暗 `#696d73` → 中 `#858681` → 亮 `#aaa391` → 暖高光 `#d0be98`；缝草沿用草地中阶。
- 木头：暗 `#62473d` → 中 `#896046` → 亮 `#b37b4e` → 暖高光 `#d9a96c`。
- 白墙灰瓦：暗 `#777982` → 中 `#a5a39a` → 亮 `#d2cbbb` → 暖高光 `#f0dfb8`；瓦暗 `#505c70`。
- 水：暗 `#326773` → 中 `#4d8887` → 亮 `#75aaa0` → 暖高光 `#afd0b0`。
- 车漆：暗 `#85362f` → 中 `#b44a3d` → 亮 `#d66d53` → 暖高光 `#f3b176`；车窗用冷蓝灰 `#2f4c5e`、`#63818b`。
- 布：暗 `#754e57` → 中 `#a36468` → 亮 `#cd8d83` → 暖高光 `#e9bca0`。
- 金属玻璃：暗 `#505b66` → 中 `#7b8990` → 亮 `#b2bdb5` → 暖高光 `#e2dfcc`。

亮级偏黄暖，暗级偏蓝灰/紫棕；主要明部在左上，右侧与右下压暗。地面纹样克制，人物和物件对比更高。

## 尺寸与锚点 QA

- 13 张标准分件逐张核对 RGBA 和像素尺寸：九材质 32×32；三人各 64×84；脚影 40×16。
- 三个人物真实身体 alpha bbox 均为 `(12, 0, 52, 84)`，包含鞋底行 y=83；均为 42 行美术像素高，头身约 2.5～3 头身，阴影独立。
- `car_mine.png` 为 86×147； alpha bbox `(0, 0, 86, 146)`，底部透明锚边让 PNG 的 y=147 脚点落在 locked rect `[461,873,547,1020]` 下边线。占地宽高没有取整。四轮按左前、右前、左后、右后绘制。
- 比例板把所有件的地面基线放在 y=230：人高84；单门高100；椅高46、宽22；圆桌宽86、高36；树高150、冠宽120；门柱高196。车的投影占地高147另列，高度数值71仅指立起高度。比例板与材质样上的尺均用独立人物成品图。
- 每个标准分件及独立投影的 2×2 最近邻方格通过源稿生成；车额外有一条 1px 透明脚点锚边以保留奇数占地尺寸。
- 可见颜色审计：脚本从所有 PNG 的非透明像素收集 RGB，确保色数 ≤64 且所有颜色都进入色板；当前共 50 色。比例板/材质样属于审图组合图，不作为独立素材件。
