# D2-F3 · 爱情篇、村子与罗曼山庄统一流程

阿鱼确认：「之前在罗曼山庄还有画面……点击去婚礼就应该去镇上这个山庄的。」目标是让爱情篇终章的「去婚礼现场」直接进苏七镇的罗曼山庄，并沿用请柬里已选的宾客姓名和形象。

阿鱼随后补充：「也可以选择去村子吧，你这几条线不能合并到一起吗。」统一交付要求为一个游戏入口、同一角色资料和连续存档。

## 完整流程

1. 爱情篇从头到尾 → 写婚礼邀请邮件 → 朋友打开请柬、填名字、选形象、盖火漆。
2. 显示「去婚礼现场 / 先去村子入住」两项选择。前者进入苏七镇原罗曼山庄，后者进入已有的村子玩法。
3. 村子提供去山庄参加婚礼的入口，山庄提供回村子的路径。山庄内仍可「跳过，直接入席」。
4. 沿用同一个角色身份、姓名和形象，保留两边游玩进度。往返和重新打开游戏后继续原进度。
5. 交付同一提交导出的完整候选，分别验证「先婚礼后村子」和「先村子后婚礼」。
