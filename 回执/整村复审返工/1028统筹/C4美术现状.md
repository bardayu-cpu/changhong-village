## 根因与处理边界

| 问题 | 判断与处理 |
| --- | --- |
| 房屋矩形草皮、黄绿/黑硬边 | 多数新房为 1536×1024 RGBA，主体外晕染仍近满画布：`house_flower.png` 的 alpha≥128 bbox=`[35,8,1511,1015]`，`house_laowu.png`=`[0,121,1526,912]`。原图内有意绘制的院地、台阶和物体投影保留；C2删除的是世界层重复院地、图外晕染和错误预乘/过滤。若仍需分离，交 C1 审单图 mask/crop，不能统一阈值或整屋重画。 |
| 像素密度、透视、光向不一 | C2确认 18 户 Sprite scale 约 0.42—0.60，源图 1536 宽映射到约 850 世界宽，本就不能形成整数纹素映射；当前是 GPU 单次 transform，不是二次采样。C1已选保留现房宽、不另烘焙或宣称无损。C2维持单次 nearest、无 mipmap，去重复层并以实际同框观感验密度；冻结房固有透视不改，新增接地件统一左上光、右下影。 |
| 院地/道路断口 | 院坝随房图、草底和道路遮罩重复，曲线路肩又缺连续边件。C2只保留一份地面几何；C4后补实际需要的院地→草、土路→稀草路肩直边/内外角，不能靠花草遮缝。 |
| 漂浮、重影、遮挡错误 | 房图已有院内投影时，不再叠可见的通用障碍椭圆阴影；障碍椭圆只做碰撞。C2以门槛、角色脚底、树干脚点排序，门热点/碰撞对位。C4只补确实缺失的台阶接触暗边和草泥碎边；亮边树才替换，并交后冠/树干/前冠与 trunk foot。 |
