## 一、整村画面为什么成了现在这样

先分清两套地面：

- **正式工程**：`godot/ayu_home/v4/assets/village/ground-pixel-1024/layers.json`，由 `core/village_ground.gd` 的旧路径绘制。仍然有穿村水带和 4 处桥（`ORDER` 含 `bridge`，水带 x=3480–3570）。`rooms.json` 里还有一个 `bridge` 房间和 `to_bridge` 出口。**违反"有小河、没有桥"。**
- **候选**：`候选/自然路肩样板-1025/overlay/...` 里的 `layout-1025.json` 和带 `panorama:true` 的 layers.json。阿鱼两张失败截图的检查点 [4616,568] 与这套候选吻合。`bundle.json` 写明没有改正式工程。

两套都不合格。逐项根因（"素材"表示要重画或补画，"接入"表示画本身可用、是接法错了）：

| 问题 | 链路（来源 → 处理 → 运行） | 类型 | 结论 |
| --- | --- | --- | --- |
| 山像贴在地上的海报 | `emei.png`（2172×724，正面立面山水）→ `village_ground.gd` 约 153–166 行先在**世界坐标**画一块纯色矩形 `mountain_rect=[0,0,4650,520]`，再把山图贴进去 → 底边硬切在 y=520，右缘硬切在 x=4650，跟草地直线相接，没有林带、雾、山脚 | **接入**为主，**素材**补过渡 | 正面山水图放进俯视地面，视角本来就对不上。山不能是地上的物体 |
| 山不是"剪影" | `emei.png` 是写实细节山水，前排绿色山脊跟地面草色同一明度，抢画面 | **素材** | 需要剪影版：金顶那种平顶长脊，2～3 层灰蓝雾色，低饱和 |
| 河像一道水墙 | `water_polygon`：东界 x≈4650–4800 一条笔直南北长条 → `water.png` 1254×1254 按 repeat=256 缩小约 4.9 倍、波纹很粗 → 跟草地直线相交，没有岸坡、浅水、岸缘 | **素材**（岸）+ **接入**（边缘混合、波纹比例） | 河在村边的位置是对的，可以保留；岸线和水纹比例要重做 |
| 路、草、水比例对不上 | `grass/yard/stone/water/bridge.png` 都是 1254×1254 大图，按 repeat 384/192/256 缩小 3～6 倍 → 每种地面的像素颗粒大小不同，也跟人物像素（世界倍率 2.0）不同 | **素材** | 地面要重画成**原生像素小图块**，跟人物用同一像素尺度，不允许再把大图缩小 |
| 路边硬 | 路是 `offset_polyline` 多边形直接盖在草上；路肩补丁只在候选里 | **接入** | 路网几何（`layout-1025`）可以保留，路肩要作为正式层接入 |

**可以保留**：`layout-1025` 的路网几何（C3 复验路面侵入清零）、河在东侧村边的位置、20 栋房子的位置、`emei.png` 作为剪影版的来源。

4. **从来没有做过同场景并排。** 整村画面从来没有在同一个检查点、13:00、同季节下跟认可参考图并排比过。

- 脚本、导航、资源齐全、哈希一致，一律不算画面或体验通过。

### 第 0 步（阻断门）：一段完整的实际游戏镜头

**先只做这一段，过了才许推广到整村。**

- **镜头位置**：东侧河边检查点 [4616,568] 附近，一屏同时出现道路、草地、河岸、水面、远山。
- **C4 画（素材）**：
  1. 地面原生像素小图块（草、土路、路肩、院坝石）：每块 32×32 或 64×64，按人物同一像素尺度画，**不再用 1254 大图缩小**。
  2. 河岸图块：草边 → 泥坡 → 浅水（颜色更浅）→ 深水，带几簇芦苇、几块石头、一处洗衣石阶。水纹按同一像素尺度重画。
  3. 峨眉剪影远景：用 `emei.png` 做来源，简化成金顶平顶长脊加 2～3 层灰蓝雾色、低饱和；另画一条可横向平铺的竹林/树林带，用来挡住山脚。
- **C2 接（接入）**：
  1. 山不再画在世界坐标的地面上：改成跟镜头的**远景视差层**，只在村北边缘出现，前面压林带和雾的渐变，底边不许出现任何直线。
  2. 河保留现在的东侧位置，改成略有弯曲的岸线，岸线用河岸图块拼，不许出现多边形直边。
  3. 草、路、水统一按世界倍率 2.0 的原生像素平铺，不允许用 repeat 缩放。
  4. 正式工程删除 `bridge` 绘制层；`rooms.json` 的 `bridge` 房间和 `to_bridge` 出口如果是村内过河桥，一并去掉，并在回执说明。
- **C3 验（独立）**：在同一检查点 13:00 夏季截一张 540×960 和一张 1280×720，跟 `用户认可风格参考.png`、`用户再次试玩-1026.png` 三张并排。逐条核对：
  - 山底边看不到直线
  - 山不像贴在地上，前面有林带或雾
  - 河岸是渐变的，不是直边
  - 草、路、水、人物的像素颗粒一样大
  - 跟参考图同一视角
- **交付物**：`回执/整村复审返工/第0步/` 里放并排图 3 张、C3 逐条核对表、改动提交号。
