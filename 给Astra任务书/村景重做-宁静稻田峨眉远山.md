# 村景重做：宁静稻田 + 峨眉远山（C4 主做）

Claude 写，2026-10-14。阿鱼看了你出的村庄布局图，说**太乱**。目标：**基于已有的屋子**，做出村庄的宁静感，房子和环境浑然天成；四季稻田；远处有峨眉山剪影。

## 原图为什么乱（这些都要去掉）

1. 整张图塞满，没有一块安静的地方，眼睛没处落。
2. 每栋房子各自围一圈墙、一块圆形土坪，成了 19 个孤岛，不像一个村子。
3. 树铺满了所有空地，一样大小、一样绿，像地毯。
4. 田的种类太碎：水田、麦田、菜地、花圃、荷塘、草垛东一块西一块。
5. 屋顶红、蓝、黑、绿混在一起，饱和度都很高。
6. 远山是普通的蓝色山脉，看不出是峨眉山。

## 构图硬要求（每条都能对着图检查）

| # | 要求 |
| --- | --- |
| K1 | **只用已有的房子**（现有 19 户 + 阿鱼家 + 四处典型建筑），不新画房子，不改房子外形 |
| K2 | **三层远近**：顶部 15～20% 是天空和峨眉山剪影；中间一条远处稻田铺到天边；下面是村子 |
| K3 | **峨眉山**：认得出是峨眉，金顶那种平顶长山脊，前低后高；用 2～3 层灰蓝雾色叠出远近，饱和度低，不画细节 |
| K4 | **稻田是主角**：地面至少 40% 是成片的稻田，大块、连片，沿地势一层层排开，田埂是细线；不再有麦田、花圃、荷塘、散落草垛 |
| K5 | **留白**：至少 35% 的画面是安静的面（稻田水面、天空、雾），上面不放任何物件 |
| K6 | **房子成组**：19 户分成 3～4 个小组团，挨着田边，背靠竹林或大树，面朝稻田；去掉每栋房子周围的围墙和圆土坪 |
| K7 | **路**：一条主路缓缓穿过村子，最多 2 条岔路；其余靠田埂走；不画环形路网 |
| K8 | **树**：只在房子后面和路口放竹丛和几棵大黄葛树；比原图少 60% 以上的树 |
| K9 | **颜色**：屋顶以青灰瓦为主，红顶最多 3 栋；整体降低饱和度；统一光线方向，暖色斜阳 |
| K10 | **无桥、无穿村河流**（沿用阿鱼之前定的规矩） |
| K11 | **四季稻田**：同一构图出四张。春天灌水的田像镜面，倒映天空和山；夏天一片青绿；秋天金黄，收割后有少量稻草垛；冬天是休耕的稻茬，带薄霜或薄雪 |
| K12 | **比例**：房子、树、路、人的比例跟阿鱼家门前院子一致，路宽够一个人走 |

## 做法和交付（省 token）

1. **先交 3 张小稿**：灰白块面构图，只画层次、稻田块、房子组团位置、路线，不上细节。放在 `回执/村景重做/小稿/`，推到 `village-deep-1010`。**等阿鱼选一张**，再往下做。
2. 阿鱼选定后，出那一张的完整版本，加四季四张，放在 `回执/村景重做/成图/`。
3. 每张图附一张 K1～K12 对照表，逐条写过或没过。
4. 这一步只出图，C2 不改游戏代码；阿鱼认可成图后，再另外派 C2 接入。
5. 只读本页和需要的房子素材，不重读历史文档；同一张图最多改三版。
