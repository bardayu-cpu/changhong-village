- 去掉了没用上的 `me`、`now`：`canChangeSeat`、`canToast` 判定本身不需要知道"现在几点"或"是谁"，调用方（云函数）传进来的数字已经是按北京时间今天算好的

- `assignSeat` 没有单独收 `seats` 参数，占用情况直接放在 `tables` 里每桌的 `seats` 数组，没有重复传一份

## 4. 建表前要确认的一处矛盾

任务卡 02 第 3 项给的 `seat` 表结构是**一人一条，换桌覆盖**：

> seat：openid、table_id、chair_no、sat_at、changed_on（日期）

但蓝图 3.2 的桌簿规则是"**坐过的桌都能写**"——如果一个人换过桌，旧的那桌按现在的表结构就查不到他坐过了（覆盖掉了），`canWriteBook` 需要的 `satTables`（我坐过的所有桌）就没法从这张表单独查出来。

两个办法，哪个我都能做，但改规则要总策划点头（固定要求 3）：

1. **只认当前桌**：`canWriteBook` 的"坐过"改成"当前坐的这桌"，换桌后不能再回旧桌写。跟蓝图字面不完全符，但表结构不用动
2. **加一份历史**：`seat` 表不变，另外加一个字段或一张小表记录"这人坐过的所有 table_id"（换桌时追加，不覆盖）。跟蓝图字面一致，表结构要多一点东西

我倾向 2（蓝图写得挺明确"坐过的桌都能写"，用户故事里也有"隔壁桌...坐到空椅子上"这种逛着写的场景），但先问过再定，不自己选。
