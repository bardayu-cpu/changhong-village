# W2 工位协作手册（给 GPT「红缘大冒险 · W2 工位」）

Claude 写，2026-11-05。**先读「补充」第〇节的最新方向：目标是尽快流畅地玩起来，不抠细节。**任务内容见 `规划/第2周任务书-补充-可操控玩法与小组.md`（下称「补充」），本手册只讲**几个工位怎么配合**。

## 一、核心规则：工位之间靠仓库里的看板交接，不靠阿鱼传话

几个工位是各自独立的对话，互相听不见。所以：

- 所有派活、交接、判过、退回，都写在仓库里的 **`回执/W2工位/看板.md`** 这一个文件里。
- **阿鱼只跟 D1 说话**（阿鱼 11/05 定）。D1 是总调度：接阿鱼的话，转成看板上的卡，派给 D2、D3、D4，并负责叫醒它们干活、催进度、收结果。
- D1 用平台能用的方式直接驱动其他工位，比如调用、子任务、发消息。如果平台做不到让 D1 叫醒别的工位，D1 要第一时间如实告诉阿鱼，并给出最省事的替代办法，不许假装已经派出去了。
- Astra（D2）仍然是游戏本身的负责人：玩法、画面、手感由它决定。D1 只管调度、守原稿和对外，不改 D2 的设计决定。
- 每个工位被叫醒后，先 `git pull`，读看板，做自己名下的卡，做完更新看板再 `git push`。

**额度**（阿鱼 11/05 定）：整个小组的周额度剩 20% 时全部停手。停手前把手上的东西提交推送、更新看板，再由 D1 告诉阿鱼做到哪里、还差什么。快到 20% 时，先保证有一个能玩的包推上去。

**D0 小助手**：不进工作流程，删掉或闲置。阿鱼有任何事都只找 D1。

## 二、看板格式（D2 建，所有工位共用）

`回执/W2工位/看板.md`：

```
# W2 看板（最后更新：时间 + 工位）

## 节点
- 11/08 上海框架 D4 判过：未到 / 已过
- 11/12 静冈+海南 回归：未到 / 已过
- 11/15 全部交付：未到 / 已过

## 卡片
| 卡号 | 内容 | 负责 | 状态 | 交付物 | 判过 |
| K01 | 操控框架：摇杆+点地+walkArea+互动按钮 | D2 | 待做/进行中/待判/退回/通过 | 提交号 | D4:过/不过（原因） D1:过/不过 |
| K02 | 上海街边可走层 walkArea 和车旁互动点 | D3 | … | 文件路径 | … |
…

## 待阿鱼拍板（D1 攒，每轮只问一次）
- 问题：…  选 A：…  选 B：…  D1 建议：…
```

状态只有六种：待做 → 进行中 → 待判 → 通过，或者 待判 → 退回 → 进行中。

## 三、谁派活给谁

```
D2 拆卡、派卡（写进看板）
 ├─ 代码卡 → D2 自己做
 └─ 美术卡 → D3 做
       ↓ 做完改成「待判」
D4 判体验、回归（真包、手机尺寸、补充里的「三之二」五条，每个玩法连玩 5 次）
       ↓ 过
D1 判原稿和规则（逐句对文案编号、四个文字槽、人物出镜、没有失败页）
       ↓ 过 → 卡片「通过」
       ✗ 任何一个不过 → 「退回」，写清原因和复现步骤，退给原负责人
```

- **D2 不判自己的卡。** D4 和 D1 都写了「过」，卡才算通过。
- 同一张卡退回三次，由 D2 决定降级，并在看板写明降级做法。
- 节点到了，所有卡都通过，D1 才汇总交付。

## 四、交接物放哪

| 东西 | 位置 |
| --- | --- |
| 代码、图 | `godot/hongyuan/`（图在 `assets/`，并更新 `manifest.json`） |
| 看板 | `回执/W2工位/看板.md` |
| D4 的录屏、截图、bug 表 | `回执/W2工位/D4/卡号-日期/` |
| D1 的核对记录 | `回执/W2工位/D1/卡号.md`（不过的才写，过的在看板写「过」就行） |
| 交给 Claude 的汇总 | `回执/W2工位/交付-11-15.md` |
| Claude 的验收意见 | `回执/Claude验收/`，D1 每次开工自己读 |

所有提交只进 `hongyuan-launch` 分支。

## 五、一个完整例子：上海一章

1. **D2**：读补充，在看板上建卡。K01 操控框架（D2），K02 上海三屏的 walkArea 和互动点位置（D3），K03 上海章接入新操控（D2），K04 停车玩法（D2）。推送。
2. **D3**：读看板，看到 K02，给街边、停车两屏标出可走范围和车门、阿晓的互动点，交一张标注图加坐标。把 K02 改成「待判」，推送。
3. **D2**：做 K01、K03、K04，出 Web 包，把三张卡改成「待判」，写上提交号，推送。
4. **D4**：拉取最新代码，打开 Web 包，按补充的「三之二」逐条判。比如：停车连玩 5 次，第 3 次车直接吸进车位、跟方向打得怎样没关系，判 K04 不过。原因写「手法无用：停车结果与操作无关」，附录屏，K04 改成「退回」。
5. **D2**：修 K04，改回「待判」。
6. **D4**：复判 K04，过；同时回归 K01～K03，都过。
7. **D1**：逐句对上海的文案编号和规则，过。四张卡都改成「通过」，看板上 11/08 节点改成「已过」。
8. 接着按同样的流程铺成都、来电……到 11/15，D1 写 `交付-11-15.md` 交给 Claude。
