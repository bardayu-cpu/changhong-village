## 1. 本周流程

```
「Toretto 来电」→ 玩家亲手点接听 → 通话（房间、手机）→ 生日、蛋糕和两束蓝花的回忆 → 关系推进的旁白 → 电话波形铺成信纸
→ 信纸白面化成静冈海面 → 码头短钓一次 → 上船 → 对话 → 点 Toretto 身边的空位 → 阿鱼「行」 → 回国后 → 领证插画 → 印章
→ 印章圆形化成套圈 → 万宁套圈 1～2 次 → 晚上 → 文昌烟花 → 两句对话 → 最后一朵烟花凝成火漆
→ 邮件边线 → 香港：亲手打开 Offer 邮件 → 带上行李走到出口 → 邮件折成信封 → 拉远回到请柬 →「写完它」
→ 终章：请柬正文 → 写自己的名字 → 选形象 → 装封 → 按住盖火漆 → 阿鱼两句话 →「入席」（本周先停在这里，下周接婚宴）
```
