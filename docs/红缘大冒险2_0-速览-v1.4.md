## 一句话

一封没写完的请柬，六段回忆，一场不散的宴席。

## 玩家怎么走

打开请柬 → 六章回忆（每章 3 分钟，一个动作，一件材料）→ 写下名字 → 入席 → 翻卡、换桌、留言簿

前半段约 25 分钟走完一次。后半段长期存在。

## 终章

六件材料齐了，请柬正文显现。玩家写下自己的名字。

然后阿鱼第一次说"我"：**"收信人这里我一直空着。名字你自己写，我怕写错。"** 全游戏唯一一次人称转换。

盖火漆。信封背面印着 6 位恢复码，换手机输进来就还是你。

## 宴席

**桌是聚出来的，不是分配的。**

1. 入席先坐"先到的桌"，簿子上已经有阿鱼写的第一句
2. 想认识人的，翻卡：看别人的自述，右滑收藏
3. 收藏的人在哪桌，就可以坐过去，每次来访换一次
4. 每桌一本留言簿，接龙。坐过就一直能写，换桌不丢旧簿子

没有配对成功，没有被拒绝。想认识一个人，唯一的动作是坐到他旁边。

自述卡四样：昵称、形象、一句自我介绍、可选 MBTI。

另有：敬酒、给新人的悄悄话（只有你能看）、礼金（金币的唯一出口，不排行）、三只猫在场地里走、紫车停在门口、阿晓站在朋友区。

入口一行字："今天还有 N 位朋友来过。"

## 这轮 review 改了什么
