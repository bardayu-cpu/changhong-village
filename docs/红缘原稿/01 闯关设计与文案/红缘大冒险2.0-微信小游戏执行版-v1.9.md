## 4. 首轮锁定事实与文案

### 4.1 玩家身份

- 请柬层：玩家是屏幕外收到邀请的朋友，不生成宾客小人。
- 回忆层：玩家始终操控阿鱼，不操控 Toretto，不生成现实玩家角色。
- 首次进入回忆时明确显示：`回忆视角：阿鱼`。
- 任务文案不能写“去帮帮她”等把玩家与阿鱼分开的表达。

### 4.2 上海事实

- 阿鱼先在上海认识阿晓。
- 两人驾驶同款紫色 BMW G42。
- 阿晓说车是哥哥的；这不代表阿晓属于 Toretto 家庭成员。
- 阿晓后来建立群聊并把 Toretto 加入。
- 上海现实见面场景中不得出现 Toretto。
- 第一章 Toretto 只能以群联系人头像出现。
- 名字始终写作 `Toretto`。

### 4.3 六句对话逐字锁定

| 人物 | 文本 |
| --- | --- |
| 阿晓 | 一样的！你也是这个颜色哈哈哈 |
| 阿鱼 | 哎 一模一样 |
| 阿晓 | 这辆是我哥的，我开出来的😂 |
| 阿鱼 | 也太巧了吧…… |
| 阿晓 | 加个微信呗～ |
| 阿鱼 | 加加加 |

### 4.4 群聊顺序逐项锁定

1. 固定过场：`后来，阿晓拉了个群`
2. 居中系统消息：`阿晓邀请 Toretto 加入了群聊`
3. 阿晓：`@Toretto 这就是那个和你车同款的姐姐哈哈`
4. Toretto：`ok`
5. 阿鱼：`你好~`

消息间隔 500～900ms，初值可为 700ms；玩家点击只加速，不要求逐条点击。聊天结束后不得再解释一次“后来阿晓拉了群”。

### 4.5 后续事实边界

来电发生在刚进入 Toretto 生日当天的深夜；同一天白天，阿鱼买一个蛋糕和两束蓝色花；收花地点为 CBD 办公室室内。当前旧背景仍不准确，必须等待真实资料确认。该段不属于首轮，不得提前制作或自行补背景。

## 5. 首轮体验硬规则

### 5.1 一个连续故事

- 不出现领奖页、章节结算页或选章页。
- 上海钢笔和成都墨水必须真实改变同一封请柬，不是点亮两个图标。
- 上海的光标／钢笔自然引出成都；成都的同一部手机自然引出来电。
- 熊猫互动不作为六次投喂门槛；做与不做都能继续主线。

### 5.2 人物唯一

- 背景优先使用空场景。
- 背景含人物时标记 `actorMode: baked`，禁止再叠同名人物。
- 独立立绘使用 `actorMode: sprite`。
- 同一人物在同一镜头最多一个视觉实例；烘焙人物、地图人物、对话立绘和电话头像都计数。
- 对话开始立即冻结移动和输入，隐藏同名世界人物；结束后在原位置恢复，旧输入不得继续。
- 每个镜头显式声明 `sceneId`、`speaker`、`actorMode`、`actorSlot`、`background`、`visibleActors`，不得继承上一句残留状态。

### 5.3 固定画面与文字

- 逻辑画布：360×640，按设备安全区整体等比缩放。
- HUD：y=0–64。
- 当前目标：y=64–116，最多两行，同时只有一条。
- 人物表演区：y=64–456。
- 对话区：y=440–624。
- 人物脚底：y=456；左槽 x≈96，右槽 x≈264。
- 文字只保留四槽：章节名、当前目标、对话／旁白、系统通知。
- 对话时隐藏目标、摇杆、物体标签和操作文字。
- 同一句话不能同时出现在顶部、中央和底部。
- 通知排队；切场清空；不能像现有成都 Toast 一样跨章残留。
- 文字进入 180～250ms，上移不超过 6px。

### 5.4 操作与移动

只使用移动、靠近、点击、按住、选择位置。行走动画按实际位移推进；阻挡时不滑步；停止后 300ms 内回到站立帧。所有可达位置必须可返回。触控取消、退后台、对话和暂停都必须清空输入。

## 6. 技术路线

### 6.1 唯一推荐

使用 **Cocos Creator 3.8 LTS 系列**建立独立 2D／2.5D 微信小游戏工程。具体补丁版本在真实开发环境验证后固定。

建议在原仓库另建：

- 分支：`feat/wechat-v19-slice`
- 目录：`wechat-minigame/`

不得修改或覆盖 `public/`、现有 H5 素材、`.openai/hosting.json` 和线上 H5。

### 6.2 可以复用

- 已确认文案和剧情数据。
- 上海移动、碰撞、寻路、驾驶纵深与接触阴影的算法思路。
- 事件幂等、离线队列和检查点设计思路。
- 经逐图确认的角色、空场景、车辆、图标与声音素材。
- 现有服务端中访客、席位、祝福等领域逻辑；首轮不接婚礼功能。

### 6.3 必须重写

- HTML、CSS、DOM 对话和跨网页跳转。
- Phaser 后续小游戏表现层。
- 人物注册、镜头状态、四个文字槽与统一输入锁。
- 浏览器 localStorage、Cookie、AudioContext 和生命周期适配。
- 微信登录、存储、网络、声音、安全区、前后台恢复与资源分包适配。
