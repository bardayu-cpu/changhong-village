# 人物新做法 · 休息间样板 v0.1

> 01 F 2026-10-04 写。阿鱼原话：「GPT的素材接进来之后，最大的问题是比例不一，方向乱走，然后整个人物非常的搞笑而你绘制的代码的人物最大的问题就是整个界面上是静止的，并没有动起来……NPC可能还是可以加一些类似这样的一些气泡，来表示他们在交流。比如说休息厅里面的人就是在那里，他们就是可以交流的。然后休息厅所有的凳子都是可以坐下的，然后，玩家是可以去坐下的……玩家操作的时候用的是你代码的色块……如果一旦产生交互对话，用图二的这种GPT画的更精美的人物来体现……GPT画一批人物的图，你根据这批图生成对应的……衣服颜色啊、性别啊，那些是一样的……对话的时候，再用这种对话框的形式来出现」；补充：「不是让 gpt 画半身，gpt 画的是全身的多个角度，在对话过程中可以根据对话变换，你只是截取了其中的一部分。因为如果要查看第三人的身份卡，那看的就是全身」。01 复述后阿鱼确认，先拿休息间做样板。
> 参考图：阿鱼给的两张截图（像素对话气泡「好多人啊」；RPG 对话框：下方蓝框、左边人物、上方名字牌）。

## 1. 场景里的人用代码画的像素小人

- **用户故事**：作为客人，我想看到场景里的人大小一致、走路方向对，不会有人看着像倒着走、一粗一细。
- **功能需求**：场景里走动、坐着的人（先做休息间这几位）都用 Claude 代码画的像素小人，跟场景同一颗粒、同一套比例（站着 84 像素高、坐着约 62）。每个小人照 GPT 画的同一个人来配：性别、发型、衣服颜色对得上。
- **交互说明**：四个方向走路、站着有呼吸一样的轻微起伏、坐下有坐姿。
- **异常处理**：哪位还没有代码小人，先用现在的样子，不空着。

休息间样板四位（GPT 宾客里挑的）：9 号奶奶、10 号爷爷（北边沙发喝茶）、5 号花衬衫叔叔、6 号戴眼镜阿姨（茶座聊天）。

## 2. NPC 冒泡聊天

- **用户故事**：作为客人，我想看到休息间的人在聊天，屋子是活的。
- **功能需求**：两三个人一组，头顶轮流冒像素对话气泡，每次几个字，过几秒消失、换下一个人。
- **交互说明**：气泡白底、深色描边、小尾巴指向说话的人；不挡玩家，玩家走近时气泡照冒。
- **异常处理**：气泡里的话先由 02 拟、标「待校对」，阿鱼在文案组校过再换。

## 3. 休息间的座位都能坐

- **用户故事**：作为客人，我想走到沙发、椅子边坐下歇一会，跟坐着的人一起聊。
- **功能需求**：休息间每个座位都能坐（沙发、单人沙发、茶座椅子）；玩家走近空座位出「坐下」按钮，坐下后再点就站起来。NPC 坐着的位子玩家不能坐。
- **交互说明**：坐下时小人换坐姿、朝向跟座位一致。
- **异常处理**：坐着时推摇杆就站起来走。

## 4. 对话框和身份卡用 GPT 画的全身人物

- **用户故事**：作为客人，我跟人说话时想看到这个人精美的样子和表情，查看别人身份卡时看到全身。
- **功能需求**：GPT 给每位画全身、多个角度和动作的人物图（比如正面、侧身、笑、惊讶、说话的手势）。点 NPC 说话时，屏幕下方弹出对话框：上方名字牌，左边是这个人的人物图（截上半部分），右边一句句的话，点一下下一句；每句话可以指定用哪个角度、表情。看身份卡时显示这个人的全身图。
- **交互说明**：对话框样子照阿鱼给的第二张图，颜色跟游戏现有界面一家。
- **异常处理**：GPT 的人物图还没到时，先用现在的样子放大顶着。
