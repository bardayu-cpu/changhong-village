## 用户故事

走进罗曼山庄大门，院子里人来人往：有人在签到桌前排着，有人在花墙前拍照，休息区几位长辈喝茶聊天。新娘妈妈迎上来说这边签到。写下名字、包一份礼金、给新人留一句祝福。走到花墙前，跟新郎新娘站一起拍张合影，拍好的照片能做成一张带小程序码的海报，存到手机或者发给朋友。签到桌旁边有本回忆册，翻开能玩阿鱼和 Toretto 相恋那几段回忆。看够了，顺着红毯走进宴会厅。

**这里不放小游戏**（阿鱼 10/2：「这里主要完成合影的功能就行了」）。

## 交互说明

- 走近签到桌、回忆册、花墙、休息区的人，出按钮；不在跟前不出
- 签到面板一步一屏；祝福那屏可以跳过（【待讨论】：要不要必须写，01 建议可跳过）
- 祝福字数【待讨论】，01 建议 1～30 字，过敏感词
- 海报：相纸页「做成海报」→ 预览 → 「存到相册」「发给朋友」两个按钮
- 走动的客人不挡路：人走过来会让开，不会把玩家卡在角落

## 异常处理

| 情况 | 玩家看到 |
| --- | --- |
| 祝福有敏感词 | 「换个说法吧」，不提交 |
| 祝福空着 | 能跳过，签到照样算 |
| 断网签到 | 照蓝图 3.1：「没连上 再试一下」，本机留草稿 |
| 海报做不出来（码没生成、断网） | 「海报没做好 先存照片吧」，照片还能存 |
| 玩家没开相册权限 | 「要先允许存到相册」，带一个去设置的按钮 |
| 已签过到再来 | 签到桌只显示「已签到」，不重复签 |
