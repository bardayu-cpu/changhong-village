## 0. 执行模型必读

### 0.1 绝对不生成

| 不生成 | 原因 |
| --- | --- |
| 阿鱼、Toretto、阿晓的角色形象 | 已有原始素材，必须沿用。重新生成会变成另一个人 |
| 樱桃小丸子的角色、标志或画面元素 | 版权。静冈只画海边城市与浦岛酒店 |
| 任何真实存在的人的相似形象 | 隐私 |
| 品牌 logo（BMW 车标、HKUST 校名等） | 车画成紫色双门轿跑即可，不画车标；香港背景沿用现有图，不新画 |
| 真实照片风、3D 渲染风、赛璐璐动画风 | 与项目风格不符 |

### 0.2 先做这一步，不做完不要生成任何素材

**第一步：读现有素材。** 打开项目 `public/assets/` 与原始素材目录，取阿鱼、Toretto、阿晓的角色图与已有场景图，确认三件事：

1. 单个角色的像素尺寸（宽×高）与头身比
2. 实际使用的颜色（取色，列出十六进制）
3. 视角（正交俯视？斜 45°？正侧？）

**第二步：用这三件事覆盖本文件第 1 节的数值。** 本文件给的是提案，现有素材是准绳。两者冲突时以现有素材为准，并在交付说明里写清改了什么。

**第三步：生成一张风格锚点图（见 2.1），阿鱼确认后再批量生成。**

### 0.3 一句话原则

新素材要能和阿鱼的既有形象放在同一屏里而不打架。这是唯一的验收标准。

## 2. 一致性工作法

**这一节是整个文件里最重要的部分。跳过它，出来的素材会互不匹配。**

### 2.1 第一步：风格锚点图

先只生成一张图，不做别的。这张图之后所有 prompt 都要引用它。

内容：一张 720×720 的拼图，包含四块——

1. 左上：调色板色块，每色标注十六进制
2. 右上：一个中性宾客角色的正面站立（不是阿鱼，是一个陌生角色），48×64 放大展示
3. 左下：一小块场景（地面、一堵墙、一棵树），展示斜 45° 视角与阴影方向
4. 右下：三个道具（钢笔、信封、火漆），32×32 放大展示

**Prompt：**

```
16-bit pixel art style sheet, single image divided into four quadrants.
Top-left: a color palette of 24 swatches in warm red, gold, purple, cream, dark neutral, bamboo green, sea blue.
Top-right: one chibi character sprite, front-facing standing pose, head is half the body height, dark outline, 48x64 pixel proportions shown enlarged.
Bottom-left: a small isometric-ish 45-degree top-down scene fragment: cobblestone ground, one brick wall, one tree, warm light from upper-left, purple-tinted shadows.
Bottom-right: three small item icons: a fountain pen, a sealed envelope, a wax seal stamp.
Hard pixel edges, no anti-aliasing, no gradients, limited palette, flat colors, warm wedding atmosphere.
Negative: photorealistic, 3d render, cel shading, soft shading, blurry, anti-aliased, gradient, text, watermark, logo, real person.
```

生成后交阿鱼确认。**确认之前不生成任何其他素材。**

确认后，这张图成为后续所有 prompt 的参考：每个 prompt 末尾都加一句 `Match the style, palette, outline weight, and lighting direction of the reference style sheet.`，并把锚点图作为参考图传入（如果模型支持）。

### 2.2 第二步：角色一次成 sheet，不分次生成

**不要**分别生成"正面""背面""侧面"再拼。同一角色的所有帧必须在**一张图里一次生成**，否则脸会变。

8 个宾客形象同理：一张图里排 8 个，一次生成。分 8 次生成会得到 8 种画风。

### 2.3 第三步：像素网格修正

图像模型产出的"像素风"通常不在真正的像素网格上（边缘有半透明像素，色数超标）。每张图生成后必须处理：

1. 降采样到目标逻辑尺寸（最近邻，不用双线性）
2. 颜色量化到 1.2 节的调色板
3. 去除半透明边缘像素，透明底做成纯 alpha 0／255 二值
4. 放大回展示尺寸时用最近邻

这一步不能省。省了就是"看起来像像素风的模糊图"。

### 2.4 第四步：并排验收

每批素材生成后，把它和阿鱼的既有形象放在同一张图里对比。头身比、描边粗细、色温、阴影方向任一项明显不同，就重做。

**阿鱼／Toretto／阿晓 补动作的做法：**

必须使用图生图或参考图功能，把现有角色图作为输入，prompt 只描述动作变化：

```
Same character, same colors, same outfit, same face. Only change the pose to: [walking, facing left, frame 2 of 4].
16-bit pixel art, 48x64, hard pixel edges, transparent background.
Do not redesign the character. Do not change hair, clothing, or facial features.
```

如果模型不支持参考图，**不要生成**，改为人工绘制或让阿鱼提供。宁可缺，不能变形。

**8 个宾客形象（一次生成一张 sheet）：**

```

Head is half of body height for all. Same outline weight and same palette for all 8.
```

确认后，每个形象再单独出动作 sheet（待机、4 方向行走、坐下、举杯、写字），做法同 2.2：一个角色一张图一次出全。

## 4. 交付规格

### 4.1 命名

```
char_ayu_walk.png          角色行走 sheet
char_guest01_idle.png      宾客待机
scene_shanghai_street_bg.png    场景背景
scene_shanghai_street_walk.png  可走层遮罩
scene_shanghai_street_over.png  遮挡层
item_pen.png / item_pen_outline.png
ui_seal.png
```

全小写，下划线分隔，不用中文、不用空格。

**不要覆盖或删除任何现有素材文件。** 新文件放新目录，旧引用通过映射保留。旧素材里的 `terotto` 拼写保持原样，只在显示名层面统一为 Toretto。

### 4.2 每张图附带

- 实际使用的十六进制色列表
- 逻辑尺寸
- 若偏离本文件规格，写明改了什么、为什么

### 4.3 验收

| 项 | 标准 |
| --- | --- |
| 网格 | 放大后像素为正方形硬边，无半透明边缘 |
| 色数 | 单张不超过 24 色，且在调色板内 |
| 透明 | alpha 为 0 或 255，无中间值 |
| 一致 | 与阿鱼既有形象并排，头身比、描边、色温、光向一致 |
| 可走 | 场景下三分之二有连续可走区域，无不可达任务点 |
| 禁项 | 无品牌 logo、无可读的真实机构名、无版权角色、无真人相似 |

## 5. 生成顺序

按这个顺序做，前一步不通过不做下一步：

1. 读现有素材，覆盖本文件数值
2. 风格锚点图 → 阿鱼确认
3. 8 个宾客形象 sheet → 阿鱼确认
4. 阿鱼／Toretto／阿晓补动作（参考图法）→ 阿鱼确认像不像
5. 序章书桌 ＋ 上海街边 ＋ 六件材料 → 够跑第一章切片
6. 其余场景按章补
7. 宴席素材
8. 动画帧

第 5 步做完就应该能跑通序章加第一章。先跑通，再往下铺。
