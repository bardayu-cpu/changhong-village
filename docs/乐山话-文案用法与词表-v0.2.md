# 乐山话 · 文案用法与词表

> 版本：v0.2
> v0.2：镇报刊名改苏七周报，游戏内镇名统一苏七镇
> 日期：2026-09-10
> 用途：镇报、阿鱼引导、物品名、店名的方言用法。给文案和执行模型
> 说明：我不是乐山人。词表分三档，**只有阿鱼给的和资料明确的才标"可用"**，其余标"待核"，阿鱼核过才上

---

## 0. 原则

镇上的朋友一半不是四川人：上海的、深圳的、香港的。方言要让他们**看得懂或者点一下就懂**，不能变成门槛。

| 档 | 谁看得懂 | 用在哪 | 怎么用 |
| --- | --- | --- | --- |
| 一档 · 通用川话 | 全国大部分人 | 阿鱼引导、镇报正文、猫事件 | 直接用，不解释 |
| 二档 · 乐山特色词 | 四川人懂，外地人不一定 | 物品名、店名、镇报栏目名 | 显示方言，**点一下出普通话**。同一个词第一次出现时自动出一次翻译 |
| 三档 · 难懂词 | 乐山人才懂 | 词典彩蛋、NPC 偶尔一句 | 只放在能点开翻译的地方 |

**用量**：一段话里最多一个方言词。全是方言就没人看了。

**语音特征不模仿**：乐山话保留入声、n/l 不分，这是听的事，文字上只在"楼卜"这类阿鱼指定的写法里体现，不自己造。

| 好好吃 | 很好吃 | 楼卜好好吃 |

| 莫得 | 没有 | 莫得菜了 |

### 二档 · 乐山特色词

| 词 | 普通话 | 状态 | 用在哪 |
| --- | --- | --- | --- |
| 楼卜 | 萝卜 | **可用**（阿鱼给） | 作物名 |
| 翘 jio 儿 | 跷脚牛肉 | **可用**（阿鱼给） | 牛肉店店名 |
| 海椒 | 辣椒 | 待核（通用川话，大概率可用） | 作物名 |
| 谷子 | 稻米 | 待核 | 作物名 |
| 茶铺子 | 茶馆 | 待核 | 店名 |
| 卡卡角角 | 角落 | 待核（资料见） | 藏东西的提示 |
| 警格导 | 注意到 | 待核（词典收录） | 镇报："警格导没，老王又偷菜了" |
| 干狮猴儿 | 很瘦 | 待核（词典收录） | 猫事件或 NPC |
| 招财咡 | 猪舌 | 待核（词典收录） | 集市摊位商品 |
| 麻螂咡 | 蜻蜓 | 待核（词典收录） | 夏天河边的装饰 NPC |
| 蝻蝻 | 蝉 | 待核（词典收录） | 夏天音效说明 |

"咡"是乐山话常见的词尾，相当于儿化。写的时候保留"咡"字，点开翻译时说明。

### 三档 · 待阿鱼补

阿鱼给的越多越好，尤其是：

- 小时候在苏稽听大人说的话
- 骂猫的话（温和的）
- 赶场时摊贩吆喝的话
- 你妈妈叫你回家吃饭的话

这些是外地人查不到的。

## 2. 在阶段 1 里怎么落

| 位置 | 原 | 改 |
| --- | --- | --- |
| 作物 | 小白菜／辣椒／稻米 | **楼卜**（4 小时）／**海椒**（1 天）／**谷子**（3 天）。点一下出普通话 |
| 牛肉店门面 | 牛肉店 | **翘 jio 儿** |
| 茶馆门面 | 茶馆 | 茶铺子（待核） |
| 家具铺 | 家具铺 | 木匠铺（待核） |
| 镇报刊名 | 苏稽周报 | **苏七周报**（镇名随游戏用苏七；"周报"不改方言，报纸名正式一点反而好） |
| 镇报栏目 | 偷菜王／收成王／新住民／评分最高的屋子／猫的一周 | 手最长的／地最肥的／新来的／最安逸的屋／猫的一周 |
| 赶场公告 | 今天赶场 | 今天走赶场 |
| 阿鱼引导·到黄葛树下 | 这棵树 我小时候就在了 | 这棵树 我小时候就在了 |
| 阿鱼引导·过桥 | 桥没栏杆 走中间 | 桥没栏杆 走中间哈 |
| 阿鱼引导·领屋 | 这间是你的 门口那块地也是 | 这间是你的 安逸不 |
| 猫事件·落落 | 落落在你家门口睡了一觉 | 落落巴倒你门口睡了一觉 |
| 偷到 | 得手 | 要得 |
| 菜熟了 | 熟了 | 熟了 |
| 包完礼金 | 收到啦～ | 收到啦～ |

**"点一下出普通话"** 是阶段 1 唯一新增的机制：方言词带虚线下划线，点了弹一行普通话。成本很低。

## 3. 阶段 4 储备：乐山话词典

走到镇上任何一个方言词、点开翻译，这个词就进你的词典。集齐 30 个词，黄葛树下的老人给你一样东西。

这是把"外地人看不懂"翻成一个收集玩法。

---

## 4. 不做

- 不用带贬义的土话（龟儿子、瓜娃子之类），哪怕熟人之间常开玩笑
- 不模仿语音（不写"日阿"这种拟音）
- 不在操作提示和系统提示里用方言。"重试""复制"就是"重试""复制"
- 不在悄悄话、留言板的输入框占位里用方言
