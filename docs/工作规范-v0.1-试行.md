## 三、一个场景怎么做（色块法，10/2 冻结，宴会厅整厅交付前不许换）

> **10/3 阿鱼定：新场景（后厅三间、草坪、湖边、果园）改用代码画像素**（「就按这个标准来做」）。标准和规矩见 `docs/罗曼山庄画风.md` 第 0 节，样板 `godot/回执/样板间-休息间-01版/`。流程变成：立项 → 灰盒摆法锁死 → 代码画成品（照 layout.json）→ 03 测、量比例 → 04 看 → 阿鱼手机验。GPT 只画人、对话立绘、插画；宴会厅、厨房照旧。下面的色块法只剩宴会厅收尾用。阿鱼直接定的，10/9 报 00

1. **立项**：先找阿鱼把真实的数一次问全（当天什么样、多少人、摆了什么），再写一页玩家说明，阿鱼点头
2. **灰盒**：02 做能玩的色块版，03 测、04 看
3. **排法锁死**：02 出 2～3 档同机位手机截图 → 阿鱼挑一张 → 摆位表锁死。**锁死前不许给 GPT 派画图**；画图期间排法冻结，想改排法回到这一步重走
4. **导色块**：03 从摆位表导整块色块图（不写字、不放人、没界面）、标注版、零件单
5. **GPT 照色块画** → 阿鱼确认样子 → **GPT 照零件单一件件出、自己照色块拼回去跟效果图对一遍才算交**（有 `交付.json` 才算交）
6. **接**：02 用接包脚本接、03 用 restore_check 量、04 看；对不上算 GPT 返工，03 出数、01 凭数打回
7. **收尾**：出码、阿鱼手机验，标「这块做完了」
- 换做法的提议一律带到 00，不许先试（00 10/2）
- 人物不从场景图里拆，单独出动作图；新人每张阿鱼审
- 出图可画成清单尺寸的整数倍，最近邻缩回；过不过看缩完的硬检查和回拼结果（阿鱼 10/2「别太死板了」）
- 同一玩法里的变种照玩法出图，零件单写全每种状态（阿鱼 10/2）

- **看图两关（阿鱼 10/2 晚，最要紧）**：GPT 出的每一类图，**先出一张目录图**（同一类每件只画正面一个样子，排一张、标编号，人物跟阿鱼那两张并排比画风），**阿鱼看过点头才细化**（别的朝向、动作）；细化完再给阿鱼看一遍，**阿鱼点头才进游戏**。原话：「GPT 出的所有的图在他去进一步的绘制之前，我都必须要先过一遍」「每一张放进游戏的图……我要核对的，始终都有图片这一个环节」
- **GPT 的图阿鱼在 GPT 那边直接看、直接改，01 不转**（阿鱼 10/2 夜：「图片的确认跟改图的工作，我在 GPT 那边让他自己弄完跟我确认就好了……你难道要帮他交一次作业吗？」）：目录图、连帧图由 GPT 给阿鱼；01 的意见写进 GPT 待办的「自查建议」；02 只接 `交付.json` 里写了阿鱼确认的正式图。01 贴给阿鱼的只有我们自己的东西（游戏截图、码）
- **画风定死**：全游戏人物照 `苏七镇奇缘/阿鱼夫妇（人物定调）.png`、`claude-新人参考-游戏里现用.png`，整场照 `001-宴会厅/交接/claude-画风基准-阿鱼10-02给的2D风格.png`（Q 版大头大眼、像素硬边、暖色）。原话：「这个画风一定是固定的，整个游戏都要维持在一个画风里面」。01 先拿它筛，写实或大人比例的直接打回，不用拿去问阿鱼

## 四、做到什么程度算过

- 画风只认画风页；比例只认「人 = 1」表，大 1.5 倍以上或小一半以下打回
- 地面连成一片无接缝；图上不叠字；宁放色块不放错图
- 截图、量位置一律按手机 540×960，长屏 1170×2532 再过一遍；截图印提交号，用 `godot/tools/shot.sh`
- 还原对照：零件 0 像素，背景容差 ≤12
- 验收每项写「验过 / 没验成 / 不适用」；有「没验成」的不出码给阿鱼，除非写明为什么先带着
- 主包不过 4 MB，每版记 `包体记录.md`；提交前检查（`check_assets.py`）不许 `--no-verify` 硬过

- **省 token 两条（10/3）**：① 核对看风险：测试交给脚本，人只看结论；画面变了才看图；小改动不走 04。② 话一次说全：派活一条写清楚，回执只写结论、提交号、风险三样，不来回问；闲着的窗口没事别去叫醒
