## 三、做到什么程度算过

- **画风**：只认一张「画风定稿板」。阿鱼点头才能改
- **比例**：只认「比例尺（人 = 1）」（`godot/回执/比例尺-人等于1.md`，抄进 ASSETS 以后以 ASSETS 为准）。大到 1.5 倍以上、或小到不足一半，打回
- **画面**：地面连成一片，没有接缝、没有没铺到的底；图上不叠字；场景图里不画人。**新人、宾客、服务员这些 NPC 单独画，新人每张阿鱼审**（阿鱼 9/24：「新人本质上是 NPC」）
- **手机**：截图、量位置一律按手机屏 540×960；每版至少在真手机上看一次
- **占位**：宁可放色块，也不放比例错、画风错的图
- **接图验收关**（任何图进游戏前，缺一步不接）：硬规格 → 摊开看 → 和定稿板并排比画风 → 量比例 → 叠走路格子 → 看接缝和空底 → 按手机尺寸截图看
- **派活说「画风不用评」时，比例、大小、遮挡照常看**
- **包体**：主包不过 4 MB，每版记

## 四、怎么说话

- **01 找阿鱼**：一天一次，一个码、最多三样要看的、要他拍板的方向。技术上的事 01 自己定，不问他
- **各窗口报 01**：三样（结论一句、commit、风险）；回复最后给阿鱼一段汇总（做了什么、你要做什么）
- **GPT**：一次一小包；任务写成文件；md 全文贴给阿鱼看；做完一包就停，阿鱼说「做下一包」再接着
- **01 派活**：一次派一件；写清验收标准（换图的必须有「比例」一条）和做到哪儿停；出码前那一段不插队

## 五、固定流程写成 skill

所有窗口在对应的时候照着走：

| skill | 用在 |
| --- | --- |
| 给 GPT 派图 | 01 写每一份 GPT 任务 |
| 接图验收关 | 任何图进游戏之前 |
| 量比例（scale-check） | 接图验收关里「量比例」那一步；有人说比例不对时 |
| 按手机屏截图（phone-screen-test） | 截图、量位置、跟屏幕边有关的测试 |
| 体验复看（experience-review） | 04 复看每一版 |
| 出一版码 | 每次出码 |
| 派活单 | 01 每次派活 |
| 换窗口交接 | 任何窗口换窗口 |
