## 0. 执行模型必读

**这是什么**：一个 9:16 竖屏 H5 游戏。阿鱼与 Toretto 的婚礼请柬。朋友点开链接，借阿鱼的视角走六段真实回忆，走完后写下自己的名字入席，在一个长期存在的云婚宴里认识其他朋友。

**你可以做的**：按本文件实现流程、地图、小游戏、宴席系统；在标注"参数"的地方调数值；在标注"草案"的地方沿用文案或提出替代（不擅自替换）。

**你不能做的**：

- 新增任何人物、事件、时间、地点、对话内容。故事事实只来自第 1 节。
- 加入改变剧情的选择支。玩家不能决定两人是否相爱、是否成家、是否领证、是否拿到工作。
- 用系统口吻写画面文案（"任务完成""解锁成功"不出现）。
- 把标注【待补】的占位内容当成正式内容实现进去。占位处显示占位符，等阿鱼提供。
- 把阿晓归入家庭成员。
- 让 Toretto 出现在第一章上海初遇现场。
- 使用旧拼写 Terotto 作为显示名。
- 在前六章旁白里用第一人称。

**读法**：第 1 节是事实；第 2 节是规则；第 3 节是完整流程脚本，按顺序实现；第 4 节是宴席系统；第 5 节是数据与技术；第 6 节是参数与验收；附录是全部文案。

## 2. 规则

### 2.1 三层结构

| 层 | 玩家是谁 | 操控谁 | 画面 |
| --- | --- | --- | --- |
| 请柬层 | 屏幕外读信的朋友 | 无 | 书桌、请柬草稿、六个材料位、桌前黑色礼服的阿鱼 |
| 回忆层 | 借阿鱼的眼睛 | 阿鱼 | 六张地图，左上角常驻"回忆视角：阿鱼" |
| 宴席层 | 自己 | 宾客形象 | 云婚宴 |

同一访客记录承接三层。阿鱼在回忆中的位置与宾客在宴席中的位置分开保存。

### 2.2 人称

| 类型 | 人称 | 例 |
| --- | --- | --- |
| 旁白、章间正文、场景说明 | 第三人称"阿鱼" | 后来阿鱼回了成都的某国企。 |
| 带说话人的对白 | 第一人称 | 阿鱼：我想。 |
| 操作提示 | 第三人称 | 点击可通行车道，帮阿鱼避开前车。 |
| 材料入请柬 | 无文案，只有一个"收纳"按钮 | — |
| 终章阿鱼对玩家说的话 | 第一人称 | 名字你自己写，我怕写错。 |
| 宴席引导 | 第一人称（阿鱼在宴席里对宾客说话） | 先坐这儿。 |

**前六章旁白全部第三人称。终章阿鱼第一次说"我"，这是全游戏唯一一次人称转换。不得提前。**

### 2.3 文案

- 白描：写看见的东西，不堆形容词，不解释情绪。
- 短：一句能说完不写两句。
- 有意义的日期直接写进句子，其余用季节和环境。
- 不用金句、排比、人生总结。
- 系统词不上画面。材料入请柬只用一个"收纳"按钮，不配旁白。

### 2.4 操作

- 点击地面自动寻路为主，虚拟摇杆备选，PC 键盘。
- 靠近可交互对象出现按钮。
- 每章入口有"直达"按钮跳过探索（第三章除外）。
- 自动保存。任何失败只有局部重试，不丢进度。
- 长对话可点击立即显示整句，可暂停，可在回忆册重读。

### 2.5 明确不做

算法匹配、单身标记、私聊、实时多人、商城与真实支付、阿鱼筛选宾客、宾客标签分桌、友谊卡、公开礼金比较、剧情选择支。

## 3. 完整流程脚本

状态机：

```
序章 → 第一章 → 第二章 → 第三章 → 第四章 → 第五章 → 第六章 → 终章 → 宴席（长期）
```

每章内部：

```
进入地图（旁白） → 探索或直达 → 活动 → 返回地图 → 回忆 → 材料入请柬 → 章末卡
```

存档点：每个箭头处。活动内另有检查点。

### 3.0 序章 · 还没写完的请柬

**目标时长**：1 分钟。

| 步骤 | 画面 | 文案 |
| --- | --- | --- |
| 1 | 链接打开。一封请柬躺在书桌上，未展开 | 按钮：打开看看 |
| 2 | 请柬展开：正文空缺、收信人留白、六个材料位空着（钢笔、墨水、信纸、印章、火漆、信封，各有轮廓） | — |
| 3 | 桌前出现黑色礼服的阿鱼（立绘） | 旁白 A0 |
| 4 | 材料位可点击查看轮廓，不强制 | 点击任一空位："还没到。" |
| 5 | 按钮 | 陪阿鱼走一遍 |
| 6 | 请柬翻页 | 第一章｜那一天，她开着那辆紫色的车 ／ 回忆视角：阿鱼 |

存档：步骤 6 后。

不做：不创建宾客形象，不填昵称，不展示完整长信。

### 3.1 第一章 · 上海，那辆紫色的车

**目标时长**：3 分钟。材料：钢笔。

**地图**：一张紧凑地图，三个相连区域。

| 区域 | 内容 | 可交互 |
| --- | --- | --- |
| 出发街边 | 街道、路灯、阿鱼与紫色 G42 | 车：点击显示"就是这辆。"；车门：进入驾驶 |
| 道路活动区 | 三车道、远景上海 | 驾驶活动 |
| 抵达区 | 东方明珠、停车位×2 | 阿晓交互点（活动后出现） |

**流程**：

1. 进入地图，旁白 A1-1（三句）
   ↓
2. 提示："开着那辆紫色的车，去东方明珠看看。"｜直达按钮："直接上车"
   ↓
3. 玩家操控阿鱼走到车旁（或直达），点"出发"
   ↓
4. 驾驶活动（见下）
   ↓
5. 抵达。镜头回到探索尺度。车停在停车位，旁边另一个停车位停着一辆一模一样的紫色 G42，阿晓站在车旁
   ↓
6. 提示："旁边那辆车……去看看。"
   ↓
7. 靠近阿晓，对白 A1-2
   ↓
8. 转场卡："后来"
   ↓
9. 手机界面：群聊 A1-3。玩家点击推进，无选项
   ↓
10. 旁白 A1-4
   ↓
11. 钢笔出现在画面中央，按钮"收纳"。点击后飞入请柬材料位，材料位下方标注"钢笔"
   ↓
12. 章末卡（见 3.8）

**驾驶活动**：

| 项 | 规则 |
| --- | --- |
| 视角 | 俯视或后视，复用现有实现 |
| 操作 | 点击左／中／右车道切换；PC 用方向键 |
| 车流 | 前方持续生成车辆，占据一到两条车道 |
| 完成条件 | 行驶到终点，且实际换道 ≥ 3 次（参数） |
| 碰撞 | 减速 1 秒，画面轻晃，无扣分、无失败 |
| 协助 | 连续 2 次碰撞后，车流间距放大 30%；连续 4 次后再放大 |
| 时长 | 约 45 秒 |
| 检查点 | 每 15 秒一个；中途退出从最近检查点继续 |
| 内部记录 | 记录换道次数与协助是否触发，不显示给玩家 |

**验收**：

- 进入地图时左上角显示"回忆视角：阿鱼"
- 直达与探索两条路径都能到达驾驶
- 车、建筑、边界有碰撞，无穿墙，无不可达点
- 驾驶前、驾驶中、抵达后未对话、对话后未拿钢笔，四种状态刷新后都能续
- 相识顺序符合 1.3；Toretto 不以任何形式出现在地图上
- 钢笔只发一次；重复找阿晓对话不再发奖
- 章末卡显示成都入口

### 3.3 第三章 · 一通电话之后

**目标时长**：4 分钟。材料：信纸。**本章无直达。**

**地图**：阿鱼的房间。夜。桌、床、窗、桌上的手机。

**流程**：

1. 进入。房间全暗，只有桌上的手机亮着。旁白 A3-1
   ↓
2. 手机屏幕："Toretto 来电"。**玩家必须点"接"**，这是本章第一个动作，不可跳过
   ↓
3. 接通。画面只显示"通话中"与秒数跳动 3 秒，无对白内容，淡出
   ↓
4. 淡入：白天。桌上多了一个蛋糕和一束蓝色的花。旁白 A3-2
   ↓
5. 提示："那之后，日子忙起来了。"｜按钮："开始"
   ↓
6. "接住"活动（见下），三波
   ↓
7. 活动结束，阿鱼靠在椅背上，长出一口气（动画）
   ↓
8. 旁白 A3-3
   ↓
9. 信纸出现，按钮"收纳"，点击飞入请柬
   ↓
10. 章末卡。本章章末卡额外一句："走了一半了。歇会儿也行。"

**"接住"活动**：

| 项 | 规则 |
| --- | --- |
| 画面 | 三条竖向轨道，标签：工作／相处／家里 |
| 元素 | 消息卡片从顶部落下，落在对应轨道。卡片只有标签，不写具体内容。工作卡："周报""会议""加班"；相处卡："Toretto""晚安""电话"；家里卡："妈""家里电话""周末" |
| 操作 | 点击卡片＝接住，卡片消失。未点击的卡片落到底部堆起来，不消失、不扣分 |
| 波次 | 第一波"频繁联系"：相处卡为主，节奏慢，25 秒。第二波"异地"：三轨均匀，节奏中，25 秒。第三波"压力"：三轨密集，节奏快，前 15 秒最密，后 10 秒渐疏 |
| 结束 | 第三波结束后，底部堆积的卡片一张张自动消失（表示"过去了"） |
| 失败 | 无。不显示接住率，不评分 |
| 检查点 | 每波开始 |
| 内部记录 | 记录接住数，不显示 |

**验收**：

- 电话必须由玩家点接，无自动接听
- 通话不显示任何对白内容
- 活动无失败、无分数、无评价文案
- 三波节奏差异明显
- 信纸只发一次

### 3.4 第四章 · 决定成为家人

**目标时长**：4 分钟。材料：印章。全游戏最慢的一章，不催。

**地图 A**：静冈海边。浦岛酒店外观、码头、停靠的乌龟船、海。

**地图 B**：上海静安（静态画面）。使用现有领证插画（带头纱）。

**流程**：

1. 进入地图 A。旁白 A4-1。Toretto 的角色形象第一次出现在画面里，站在码头。这是玩家第一次看见他站在阿鱼旁边——不加任何旁白说明，让画面自己说
   ↓
2. 提示："去码头，Toretto 在那儿。"｜直达："直接去码头"
   ↓
3. 走到码头，靠近 Toretto，出现"钓鱼"按钮
   ↓
4. 钓鱼活动（见下）
   ↓
5. 钓到后，"上船"按钮。两人上乌龟船，船往回开
   ↓
6. 对白 A4-2，含"挪过去"动作
   ↓
7. 船靠岸。回到码头。桶里有鱼（持久状态）
   ↓
8. 转场卡："回国后。"
   ↓

   ↓
10. 印章出现，按钮"收纳"，点击飞入请柬
   ↓
11. 章末卡

**钓鱼活动**：

| 项 | 规则 |
| --- | --- |
| 操作 | 点击甩竿（有摆动幅度指示，任意时机都能甩出，幅度只影响距离不影响结果）→ 等待 3～6 秒 → 浮标下沉、出现"收线"提示 → 在 1.5 秒窗口内点击 |
| 完成 | 钓到 1 条 |
| 失败 | 错过窗口，鱼跑了，重新甩竿。连续 2 次错过，窗口放大到 2.5 秒 |

## 4. 宴席

### 4.1 空间

| 区域 | 内容 | 谁能坐 |
| --- | --- | --- |
| 入口 | 礼服的阿鱼与 Toretto 迎接；一行字"今天还有 N 位朋友来过"（N 为 0 不显示） | — |
| 新人桌 | 阿鱼、Toretto、礼金盘 | 不能坐；可敬酒、写悄悄话、包礼金 |
| 亲友主桌 | 家人（名单私下提供） | 家人 |
| 宾客桌 | 按到场顺序自动开桌，每桌 10 人；桌满开"同桌·二"紧挨 | 全部宾客 |
| 留言簿 | 每桌一本，桌中央 | 见 4.4 |
| 三只猫 | 在场地里走动；走近可摸，摸一下有小动作；点击显示名字与一句介绍（A8-3） | — |
| 紫色 G42 | 停在门口；走近显示"就是这辆。" | — |
| 阿晓 | 站在普通宾客区，一句话（A8-4） | — |
| 回忆册 | 从请柬重访六章 | — |
| 我的席位 | 自己的信息面板 | — |

场地分区载入，不一次铺满。

### 4.2 首次入席引导（顺序固定）

1. 入口，新人迎接。阿鱼：A8-1 首句
   ↓
2. 自动走到"先到的桌"坐下。这桌的留言簿已有阿鱼写的第一句（A8-2）
   ↓
3. 提示留言簿："这桌的簿子，随便写。"
   ↓
4. 提示新人桌："想跟我们说点什么，去那边。"
   ↓
5. 提示礼金：走近新人桌时出现礼金盘
   ↓
6. 最后提示翻卡："想认识人的话，翻翻看。"

六件事都可用，但只按这个顺序提示一次。

### 4.3 翻卡与坐桌

**原则：桌不是分配的，是聚出来的。右滑不是配对，是收藏。没有匹配成功，也没有被拒绝。想认识一个人，唯一的动作是坐到他旁边。**

**自述卡**（入席后可选加入；不加入的人不出现在卡堆，也不能翻；家人默认不加入）：

| 字段 | 必填 | 限制 | 可见 |
| --- | --- | --- | --- |
| 昵称 | 是 | 5.3 | 全部宾客 |
| 像素形象 | 是 | 预设 | 全部宾客 |
| 自我介绍 | 是 | ≤60 字，占位"简单写一下自己"，过敏感词 | 加入翻卡的宾客 |
| MBTI | 否 | 16 选 1 或不填 | 加入翻卡的宾客 |
| 请柬完整标识 | 系统 | 形象上一枚亮着的火漆印 | 全部宾客 |
| 现在坐哪桌 | 系统 | — | 全部宾客 |
| 和你想认识的 X 位同桌 | 系统 | — | 仅自己看别人卡时显示 |

填卡时明示："加入翻卡的朋友都能看到这张卡。"

**卡堆**：

| 规则 | 说明 |
| --- | --- |
| 顺序 | 随机 |
| 不出现 | 自己、新人、家人、未加入翻卡者、已右滑者、已同桌者 |
| 左滑 | 跳过；下次来访可能再出现 |
| 右滑 | 进"想认识的人"列表；不通知对方 |
| 每次来访上限 | 20 张（参数） |
| 卡上不显示 | 谁右滑过他、他右滑过谁、被翻过几次 |

**坐桌**：

| 规则 | 说明 |
| --- | --- |
| 首次 | "先到的桌"：当前未满的最新一桌 |
| 换桌 | 从"想认识的人"列表任选一人，点"坐过去"；每次来访限 1 次（参数） |
| 桌满 | 开"同桌·二"，留言簿共用 |
| 想认识的人在不同桌 | 自己选一桌 |
| 想认识的人换走了 | 收到"某某去了别的桌"，可跟过去（算一次） |
| 坐过去后 | 同桌的人下次来访看到"有人坐到这桌了" |
| 关系边 | 每次同桌记一条边，带时间 |

### 4.4 留言簿

一桌一本，平铺，时间正序，不做楼中楼。

**权限跟着"坐过"走**：坐过这桌的人永久可读可写，换桌不失去旧簿子。新人可读全部。

| 项 | 规则 |
| --- | --- |
| 内容 | ≤100 字，纯文本，过敏感词 |
| @ | 可 @ 坐过这桌的任何人；被 @ 者下次来访看到提示 |
| 未读 | 上次来访之后的新增高亮 |
| 删除 | 自己的可删；阿鱼可删任何 |
| 分页 | 超过 100 条分页 |
| 我的簿子 | "我的席位"里列出坐过的所有桌，逐本进入 |

留言簿是唯一的对话场所。不做私聊。

### 4.5 敬酒、悄悄话、礼金

| 行为 | 体验 | 数据 |
| --- | --- | --- |
| 敬酒 | 走近任意宾客或新人，选预设问候（5 条，参数），播放举杯 | 发送者、接收者、问候、时间 |
| 悄悄话 | 走到新人桌写，≤200 字 | 仅阿鱼可见；阿鱼可逐条公开到入口留言墙 |
| 礼金 | 走近新人桌出现礼金盘；选择包多少金币；只能包手上有的 | 宾客、数额、时间；总额仅阿鱼后台可见 |

礼金不排行、不显示谁包了多少、不催、不包也没有任何影响。金币的唯一出口是礼金；包完后请柬层不再显示余额。文案 A8-5。

### 4.6 可见范围

| 内容 | 谁能看 |
| --- | --- |
| 昵称、形象、火漆印、所在桌 | 全部宾客 |
| 自我介绍、MBTI | 加入翻卡的宾客 |
| 想认识列表、左右滑记录 | 仅自己 |
| 留言簿 | 坐过该桌者（永久）、新人 |
| 敬酒 | 发送者与接收者 |
| 悄悄话 | 仅阿鱼 |
| 礼金数额 | 仅阿鱼 |
| 今日来访 | 数字，全部宾客 |
| 关系全图 | 仅阿鱼后台 |

### 4.7 回访

再次来访从自己当前的桌开始。入口处显示上次之后的变化："3 条新留言、1 人坐过来、被 @ 1 次"。

没有推送。回访靠阿鱼在朋友群里通知。

### 4.8 阿鱼后台（首版为脚本或受保护接口）

列出宾客；改昵称；隐藏宾客；合并重复宾客；按昵称查恢复码；删任意留言；公开悄悄话；查看礼金总额；导出关系全图（含 MBTI 维度）；敏感词回扫。

## 5. 数据与技术

### 5.1 身份

以本机浏览器存储识别。微信内置浏览器、外部浏览器、另一台设备各自独立。

**恢复码**：

| 项 | 规则 |
| --- | --- |
| 生成 | 入席时自动生成 6 位，不重复，避开 0／O／1／I |
| 展示 | 终章信封背面；"我的席位"随时可看、可复制 |
| 使用 | 新设备打开链接时可选"我来过"，输码恢复 |
| 恢复 | 全部进度与宴席状态 |
| 冲突 | 新设备已有进度时二选一，不自动合并 |
| 遗失 | 找阿鱼，后台按昵称查 |
| 不是 | 账号。无密码、无手机号、不可改 |

### 5.2 存档

每位访客一条记录，至少包含：

```
访客ID、恢复码
当前层（请柬／回忆／宴席）、当前章
回忆层：阿鱼所在地图、位置、任务节点、活动检查点、每张地图的持久状态
请柬：六件材料、正文状态、收信人
奖励记录：每章金币是否已发、已发数额
宾客：昵称、形象、改名次数、是否加入翻卡、自述卡、MBTI
宴席：当前桌、本次来访换桌次数、坐过的桌列表、想认识列表、已翻卡记录
社交：留言簿已读位置、敬酒记录、悄悄话、礼金记录
来访：上次来访时间、来访次数
```

阿鱼位置与宾客位置分开保存，互不覆盖。

### 5.3 文本校验

昵称、自我介绍、留言、悄悄话以外的全部自由文本过校验。悄悄话不过滤。

| 项 | 规则 |
| --- | --- |
| 昵称长度 | 2～12 个图形簇 |
| 昵称字符 | 中英文、数字、常用 emoji；禁纯符号、纯数字 |
| 保留名 | 阿鱼、Toretto、Terotto、阿晓、新郎、新娘、家人称呼（服务端匹配，不进前端包） |
| 敏感词 | 前端即时＋服务端二次；命中只提示"换一个吧"，不说命中什么 |
| 校验服务不可用 | 不放行 |

细则见配套需求文档。

### 5.4 服务端约束

- 一次性奖励：每章材料与金币只发一次，服务端校验。
- 换桌：每次来访 1 次，桌容量 10，服务端校验。
- 留言簿写入：校验写入者坐过该桌。
- 礼金：不能超过持有金币。
- 存档：客户端提交，服务端合并；断网时本地缓存，恢复后重试。
