## 0. 一句话

镇上有一所小学，是阿鱼长大的地方。进去上课，学做跷脚牛肉、米花糖、花生糖。学会了做出来，在老街开个店卖给镇上的人。

## 1. 经济闭环

```
地里种（阶段 1）
   ↓ 楼卜、海椒、谷子、花生、黄豆、花椒
小学上课（本阶段）
   ↓ 学会配方
做东西
   ↓ 翘 jio 儿、米花糖、花生糖、豆腐脑、蘸碟
卖
   ├─ 卖给系统摊：保底价
   ├─ 家门口摆摊：住民路过买，价自定
   └─ 老街开店：铺面有限，赶场日客流翻倍
   ↓ 币
买种子、买家具、租铺面、送礼
```

币只在镇内流通，不做真实货币。

## 2. 苏七小学

### 2.1 地方

**位置已确认：镇政府对面。** 镇政府是一栋不能进的楼，对面就是校门。

校门、操场、两间教室、黑板报、食堂。校门外：一个豆腐脑摊、两家文具店。

#### 阿鱼给的童年细节（已确认）

| 细节 | 游戏里 |
| --- | --- |
| 小学在镇政府对面 | 地图定位。镇政府不可进，阿鱼路过一句："这是镇政府 里面没啥好玩的" |
| 6 毛一碗的咸豆腐脑 | 校门口豆腐脑摊，只早上 6～10 点开。**全镇最便宜的吃的：6 币一碗**，牌子上写"六毛"。不学做，只能买。不涨价，不受赶场影响 |
| 隔壁都是文具店 | 校门两边各一家文具店。**配方册就是这里买的作业本**，5 币，封面写学号。也卖粉笔，不同颜色写班级黑板报 |

校园里另放阿鱼小时候的东西：她坐过的座位、操场某个角落、食堂窗口。每样点一下一句话，阿鱼自己写。这是全镇唯一带阿鱼童年的地方。

**咸豆腐脑**：待阿鱼确认是"咸"字。

### 2.2 入学

| 步 | 内容 |
| --- | --- |
| 报名 | 走进校门，领学号。学号按报名顺序 |
| 配方册 | 去隔壁文具店买一本作业本，5 币。学会的配方记在里面 |
| 班级 | **同一周报名的人同班**。每周一开新班 |
| 黑板报 | 每班一块，同班的人能写。同桌留言簿的逻辑搬到班级 |
| 毕业 | 学完三门课，毕业证挂屋里 |

班级是继"同桌""邻居"之后第三种把人聚在一起的方式，而且是按时间聚的——同一周进镇的人本来就有话说。

### 2.3 课程

每门课一个小游戏。学会了记在配方册里，以后做不用再上课。

| 课 | 原料 | 小游戏 | 产出 | 参考 |
| --- | --- | --- | --- | --- |
| **翘 jio 儿** | 牛骨（系统摊买）、药包（系统摊买）、海椒、花椒 | 三步：①熬汤，放料后**真实 12 小时**（跟种菜一个逻辑）②切牛肉，节奏点击，切厚了扣分 ③配蘸碟，海椒、花椒、盐三个滑块，比例对了才香 | 一碗翘 jio 儿 | 真实工艺：清汤派，牛骨牛杂加药材熬十二小时 |
| **米花糖** | 谷子、糖 | 三步：①炒米，翻锅节奏，糊了重来 ②熬糖，火候条，到位松手 ③压模切块，画线切，切歪了不好看 | 米花糖一盒 | 省级非遗，用当季新米 |
| **花生糖** | 花生、糖 | 两步：①炒花生 ②熬糖拌压 | 花生糖一盒 | 阿鱼指定 |
| 豆腐脑 | 黄豆 | 磨豆、点卤、加料（酥肉、粉条） | 一碗豆腐脑 | 早市小吃。可选课 |
| 蘸碟 | 海椒、花椒、盐 | 只有配比一步 | 蘸碟一份 | 翘 jio 儿的一部分，单独也能卖 |

新增作物（阶段 4）：花生（2 天）、黄豆（2 天）、花椒（4 天，树，长一次收多次）。

### 2.4 品质

每次制作按小游戏成绩出品质：普通／好／巴适。品质影响售价和送礼时对方看到的字。

不做失败品。做砸了也是"普通"，不浪费原料。

## 3. 卖

### 3.1 三个去处

| 去处 | 谁买 | 价格 | 条件 |
| --- | --- | --- | --- |
| 系统摊 | 系统 | 保底价，固定 | 随时 |
| 家门口摆摊 | 路过的住民 | 自定，上限系统价 ×3 | 有毕业证 |
| 老街铺面 | 全镇 | 自定 | 租到铺面 |

### 3.2 老街铺面

| 项 | 规则 |
| --- | --- |
| 数量 | 10 个住民铺面，先到先得 |
| 租金 | 每周 100 币，周一自动扣。扣不起收回，货退给你 |
| 店名 | 自填，过敏感词，可用方言 |
| 招牌 | 从 5 种样式选 |
| 赶场日 | 老街客流 ×2，系统 NPC 也会来买 |
| 排队 | 想租的人排队，有人退租按队列给 |

铺面稀缺是故意的。谁开了店、卖什么、多少钱，会变成镇上的谈资。

## 4. 送礼

做出来的东西可以送人。送到对方家，摆在他桌上，写"老王送的米花糖·巴适"。对方可以吃掉（消失）或留着（摆件）。

这是比留言更轻的社交动作：不用想说什么，送一盒糖就行。
