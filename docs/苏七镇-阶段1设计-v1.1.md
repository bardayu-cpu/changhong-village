## 0. 执行模型必读

**阶段 1 只做第 3 节列出的东西。** 没列的不做，包括：工作小游戏、装修系统、好友系统（只做 3.10 的范围）、节气活动、钓鱼、六章 RPG、支线、收集物联动。这些在后续阶段。

**第一个技术决定**（v1.1 标注：已定 Godot 4.7.2，微信版第 12 版真机能开，不再评估；以下原文保留存档）：现有项目是 Phaser 3 的 H5。执行模型在写任何代码前，先评估两条路并给出建议：

1. Phaser 3 通过社区适配层跑在微信小游戏里
2. 换引擎（Cocos Creator 等微信官方支持的引擎），像素素材和数据结构迁过去

评估标准：适配稳定性、小游戏包体限制、开放数据域（好友排行）的接入难度。**评估结果交阿鱼决定后再动手。**

**不能做的**：

- 不做注册、不做公开入口。入镇只能通过某个住民的邀请链接；每个人的链接都记录是谁的
- 不做真实货币、不做支付
- 不给人打分，只给屋子和菜打分
- 不做实时多人。全部异步
- 不在阿鱼没确认的情况下使用苏稽的真实店名、人名。**罗曼酒店**（阿鱼也写作罗曼山庄）是阿鱼确认可用的真实地名，在镇子边上
- 镇名、小学名、镇报名在游戏内一律用**苏七**：苏七镇、苏七小学、苏七周报。真实地名苏稽只出现在设计文档里，不进画面和文案
- 现有像素风背景里阿鱼穿的礼服是婚礼当天的真实礼服之一，**不重绘、不改**

## 1. 镇子是什么

一个所有朋友一起住的镇子，游戏里叫**苏七镇**。以四川乐山苏稽古镇为底——阿鱼在这里长大。真实地名苏稽只出现在设计文档里，游戏内的镇名、小学、镇报一律用苏七。

入口是阿鱼和 Toretto 的婚礼：先到镇子边上的罗曼酒店吃席（婚宴真实地点），吃完走进镇上，过桥到河对岸，领一间屋、一块地，就住下了。

每天做的事：种菜、收菜、偷邻居的菜、逢单日赶场、去别人家串门留言、看看新人家的猫和狗。

镇子有自己的钟和日历（细节见《苏稽古镇 · 实地元素与玩法映射》）：逢单日赶场，夏天河水漫过桥面。阶段 1 只做这两条。

## 2. 内容引擎：镇子自己生产内容

阿鱼不需要定期发东西。镇子靠下面五样东西一直有新内容：

| 引擎 | 内容 | 频率 |
| --- | --- | --- |
| 作物 | 按真实时间生长、成熟、烂掉。每次回来地里都不一样 | 持续 |
| 偷菜 | 邻居之间的偷与被偷，每次都有新的"XX 偷了你的菜" | 持续 |
| 镇报 | 系统每周一自动生成一期：本周谁偷得最多、谁收成最好、新来了谁、谁家评分最高 | 每周 |
| 猫和狗 | 三只猫一只狗在镇上随机走动，会出现在任何人家门口。每天随机一件小事："落落在你家门口睡了一觉" | 每天 |
| 住民动态 | 任何人可发一条状态 | 住民自发 |

阿鱼的"新人动态"保留，但无日程。她想发就发，置顶公告板。

## 3. 阶段 1 的全部内容

### 3.1 进镇

1. 点开某位住民发的邀请（小游戏分享卡片，带该住民的 ID）。第一批来自阿鱼和 Toretto
   ↓
2. 微信授权，取 openid。这是身份，换手机不丢
   ↓
3. 填昵称（规则沿用：2～12 字，公开，过敏感词）
   ↓
4. 选形象（8 个预设，沿用美术包）
   ↓
5. 两分钟剪辑：六章各一张图一句话（占位，后续换成完整六章）
   ↓
6. **罗曼山庄**：签到、回忆册、合影、吃席、悄悄话，六块画布，见《罗曼山庄-第一关蓝图-v0.1》。第 5 步的剪辑放在山庄签到处的回忆册里
   ↓
7. 出山庄大门，沿民建路往东南到本地人集市，往西南到镇政府，到小学门口黄葛树下（路线按阿鱼 9/15 红标，见《世界观 v0.1》3.2）
   ↓
7a. 黄葛树（小学门口）：树上多了一片叶子——你。点一下看到谁带你进来的
   ↓
7b. 走古镇观光街
   ↓
8. 过茹公桥到河对岸，系统按到镇顺序分配下一间屋。走过去，进门
   ↓
9. 屋门口一块地，六格，空的。种子铺给三包免费种子
   ↓
10. 种下第一棵。提示："熟了会通知你。"——此处请求订阅消息授权

进镇全程约 7 分钟。第 7、8 步是刻意的：让每个人第一次就把镇子走一遍、把桥过一遍。

### 3.3a 两个集市与赶场

真实地理带出的经济玩法：本地人集市在北，游客集市在南。

| | 本地人集市 | 游客集市 |
| --- | --- | --- |
| 位置 | 镇北路口 | 河南岸，住宅区东 |
| 开放 | **只有逢单日（赶场）开** | 天天开 |
| 收菜价 | 基准价 | 基准价 ×2.5 |
| 卖种子 | 基准价 | 基准价 ×2 |
| 人流 | 赶场日 NPC ×2 | 常年有 NPC |

**跑腿换差价**：楼卜在本地集市卖 5 币，走到游客集市卖 12 币，代价是多走一趟。玩家自己权衡。

逢单日本地集市开，人往北；双日只有游客集市，人往南。镇上的人流每天在变。

赶场日公告板顶部显示"今天走赶场"。不推送，让人自己发现规律。

### 3.4 偷菜

**这是阶段 1 的核心。** 不认识的人因为偷菜互相认识。

| 项 | 规则 |
| --- | --- |
| 能偷什么 | 别人地里熟了的菜 |
| 一格 | 只能被偷一次；偷走该格产出的 30%，主人收剩下的 70% |
| 每人每天 | 最多偷 10 格 |
| 对同一家 | 每天最多偷 3 格 |
| 主人看到 | 回家时地上有脚印，点开："老王偷了你两棵楼卜。"推订阅消息 |
| 看家 | **喜多**（柯基）可以借来看家，24 小时。借了之后喜多蹲在地边，偷菜者有 50% 概率被"喜多盯着"，偷不到。每天可借一次，免费 |
| 反偷 | 无特殊机制。想报复就去偷回来 |
| 记录 | 每次偷菜记一条边：谁、偷了谁、几棵、何时 |

### 3.8a 踢球接龙

喜多爱踢球。这是镇上第一个"一个人做不成"的事，而且异步。规则同 GDD v1.2 的 4.6。

**用户故事**：路过黄葛树下看到一个球，踢一脚，球滚开停住。晚上再来，球边写着"今天被踢了 9 脚"。第二天回来，昨天全镇踢满了 10 脚，自己多了 5 币和一枚喜多印。

**功能需求**

| 项 | 规则 |
| --- | --- |
| 球 | 4 个：红、黄、蓝、一个破的旧球 |
| 位置 | 每天 0 点随机散在操场、黄葛树下、老街、桥头四个点；用日期做种子，同一天所有人看到的位置一样。喜多自己带着一个到处走，只是视觉 |
| 踢 | 走到球边点一下，球滚开一小段停住，还在原来那个点附近，等下一个人 |
| 限制 | 一人一天在同一个球上只能踢一次；四个球各踢一次，一人一天最多 4 脚 |
| 目标 | 全镇当天累计 10 脚，喜多高兴；当天踢过的人各得 5 币和一枚"喜多印" |
| 显示 | 球边显示"今天被踢了 N 脚" |
| 结算 | 次日 0 点结算前一天：达标发币和印，不达标什么都不发；计数清零 |
| 服务端 | 踢球次数、每人每球一次、达标判定都在服务端 |
| 参数 | 球数 4、目标 10 脚、奖励 5 币，可调 |

**交互说明**：靠近球出现"踢一脚"按钮；踢后球滚动约 1 秒；球边常驻当天计数；达标后第二天进镇弹一次"喜多高兴了"，带 5 币和喜多印；喜多印累计保存在住民记录里，不排行，在哪展示待讨论。

**异常处理**

| 情况 | 处理 |
| --- | --- |
| 今天已踢过这个球 | 按钮置灰，提示"这个球今天踢过了" |
| 隔着距离点球 | 不响应，走近才出按钮 |
| 两人几乎同时踢同一个球 | 服务端按到达顺序各记一脚，球的落点以后到的为准 |
| 当天不满 10 脚 | 不发奖，不提示 |
| 跨日 | 按北京时间 0 点切换；0 点后踢的算新一天 |
| 断网时踢 | 本地不动球，提示"没连上 再试一下" |

### 3.9a 方言词翻译

### 3.10 关系网（邀请树）

**谁把谁带进来的，就是关系本身。** 不用任何人声明自己是谁。

| 概念 | 设计 |
| --- | --- |
| 根 | 阿鱼和 Toretto，两根主枝 |
| 枝 | 每个住民一条自己的邀请链接（小游戏分享卡片带住民 ID）。用谁的链接进来，就长在谁的枝上 |
| 叶 | 每个住民一片叶子。黄葛树上的叶子数＝镇上人数，树跟着镇子长 |
| 看 | 黄葛树下点一下展开整棵树；点叶子看是谁、谁带进来的、他带了谁 |
| 标注 | 屋门口一行"XX 带进来的" |

**三层关系：**

| 层 | 是谁 | 怎么变好友 |
| --- | --- | --- |
| 同枝 | 带你进来的人；你带进来的人 | 自动好友 |
| 邻叶 | 同一个人带进来的人 | "可能认识的人"最前排；一键请求，对方同意即成 |
| 扩列 | 好友的好友（两跳内） | 在好友屋里看他的好友，可发请求 |

两跳之外只能通过一起做事进入"可能认识的人"：偷过你的菜、同一周进镇。

**好友能做什么（阶段 1）**：地图上有标记；进屋不受"谢绝串门"限制；可能认识的人里显示共同好友数。

**可能认识的人**：公告板一栏，最多 10 人，按信号排：邻叶 > 共同好友数 > 偷过你的菜 > 同一周进镇。

**配额与剪枝：**

| 项 | 规则 |
| --- | --- |
| 配额 | 每人 5 个名额起步；每住满一周（按 7.2 定义）加 1 |
| 剪枝 | 阿鱼后台可封一个人，也可封整条枝（该枝所有人转为只读） |
| 总开关 | 阿鱼后台可切"只有阿鱼和 Toretto 能邀请"。**建议前两周开着这个开关**，第一批人住下来再放开 |

**术语**：不用"上线／下线"。用"谁带你进来的""你带了谁"。功能名"扩列"，长辈界面显示"认识新朋友"。

### 3.10a 月老庙 · 牵红线

镇上有月老庙。月老牵红线，游戏叫红缘大冒险，核心机制就是牵线。阿鱼和 Toretto 也是被人牵的线。

| 项 | 规则 |
| --- | --- |
| 位置 | 河西岸，过桥后往西走一段 |
| 谁能牵 | 任何住民 |
| 牵谁 | **两个都不是自己的人**，且两人当前不是好友。自己牵不了自己 |
| 附言 | 一句话，≤30 字，写给这两个人看（"你们俩都会为一只猫改行程"）。过敏感词 |
| 通知 | 两人下次来访各收到一条："XX 在月老庙给你和 YY 牵了条线"。看得到附言、对方昵称和形象 |
| 成 | **两人都点"接"才成**。成了两人直接成好友，关系树上多一条红线 |
| 不成 | 任一方点"不了"或七天不理，线自动断。**发起人不会知道是谁拒的**，只显示"这条线没接上" |
| 配额 | 每人每周 2 条 |
| 红线的样子 | 关系树上红色，比普通的枝细，会轻微飘动 |
| 红线榜 | 庙里一块牌子：牵成最多的前 5 人。**只显示牵成的数量，不显示牵了谁** |
| 屏蔽 | 屏蔽过的人之间不能被牵；被同一人牵过两次不成，此后他不能再牵这两人 |

**关键判断：牵线是把两个人介绍给彼此，不是配对。** 不显示"匹配度"，不显示单身，不分性别，不做任何暗示。就是"我觉得你俩会聊得来"。

一句纪律：这是全镇唯一一个"由第三个人发起"的社交动作。它成不成由被牵的两人定，牵的人只负责开口。

### 3.10b 月老庙内殿 · 许愿与求签

去月老庙许愿求个好姻缘，本来就是这座庙的用法。内殿照这个来做。

**没许愿的人看不到内殿有谁，也看不到内殿长什么样。** 这是底线：在熟人圈里，"我在找"被同事、表哥、发小看见，比在陌生人产品上被看见难受得多。

| 项 | 规则 |
| --- | --- |
| 许愿 | 走进内殿许愿。**不填任何资料**——没有性别、年龄、身高、职业、择偶条件，一个字段都没有。许了愿才能求签，也才会出现在别人的签里 |
| 推荐语 | **只有朋友能写**，署名，≤50 字，每人最多 5 条。过敏感词。没许愿的人也能写 |
| 求签 | **每天一支**。摇签筒，得一支签 |
| 签上 | 一个人的形象、昵称、朋友写的全部推荐语。没推荐语的显示"还没有人写" |
| **不做签的等级** | 不分上上、中平、下下。分等级等于给人打分，在熟人里太伤人。签面只写一句与人无关的吉利话 |
| 收下 | 存进自己的签筒 |
| 放回 | 放回签筒。**七天后可能再抽到**——现实里对一个人的看法本来就会变 |
| 接上 | **双方都收下了对方**才显示。两人看到彼此的牌与全部推荐语，以及一行"去找 XX"——XX 是给对方写过推荐的人，或两人所在枝的共同上游 |
| 之后 | **游戏不管。** 无站内聊天，无联系方式字段。由那个真人去牵 |
| 不会抽到 | 自己、同枝的人、家人、屏蔽过的、已收下的、七天内放回的 |
| 没人可抽 | "今天没签了 明天再来" |
| 撤愿 | 随时。愿牌、推荐语、签筒记录全部清空。外殿的牵红线不受影响 |

**为什么是求签不是滑卡**：镇上人少，一堆卡两分钟滑完就见底；一天一支，池子小反而合适，而且这是全镇最强的回访理由——明天的签还没求。"放回签筒"也比"左滑跳过"温和，放回去的不是删掉这个人。

**关键判断：整个内殿只有朋友能替你说话。** 自述人人会写，一个认识你八年的人愿意署名说你实在，这是别处没有的。

**关键判断：接上之后由真人完成介绍。** 一个活人在中间，双方都不尴尬，聊不下去也有人兜着。这正是熟人背书的价值，也让写推荐的人自然成为媒人。

**措辞纪律**：全篇不出现相亲、交友、单身、脱单、匹配、CP、征婚。只用：月老庙、许愿、求签、收下、放回、接上了、写推荐、撤愿。

## 7. 验收

### 7.1 功能

两位测试者，两台手机：

1. A 通过邀请进镇，吃席，领屋，种菜
2. 4 小时后 A 收到"熟了"推送
3. B 进镇，走到 A 家，偷两格，给屋子打分，留言
4. A 回来看到脚印、被偷记录、评分、留言，收到推送
5. A 借喜多看家；B 再偷，被拦
6. 周一 0 点镇报生成，两人都在里面
7. 单数日期打开，本地集市开、公告显示"今天走赶场"；双数日期本地集市关，游客集市仍开且价高
8. 两人合计捐满 30 棵，第一盏桥灯亮，灯下有两人名字
9. B 用 A 的链接进镇：树上 B 长在 A 的枝上，两人自动好友，B 屋门口写"A 带进来的"
10. C 用 A 的链接进镇：B 和 C 互为邻叶，出现在彼此"可能认识的人"第一位；B 发请求，C 同意，成好友
11. 阿鱼后台封 A 的枝，A、B、C 全部转只读
12. D 在月老庙给 B 和 C 牵线并写附言；B 接、C 接，两人成好友，树上出现红线；再测 C 不接，线断，D 只看到"这条线没接上"
13. B 和 C 各自许愿；D 给 B 写推荐；B 求签抽到 C 并收下，C 求签抽到 B 并收下，双方看到"接上了 去找 D"；当天再求签显示"今天没签了"；未许愿的 A 打开月老庙只看到外殿，看不到内殿存在
14. 当天 A、B、C、D 各在至少三个球上踢一次，合计 ≥ 10 脚；B 再踢同一个球被拒，提示"这个球今天踢过了"；次日四人各得 5 币和一枚喜多印，球边计数清零
15. 阿鱼后台看到全部记录

### 7.2 留存（决定后面做不做）

**"住下来"的定义**：第 7～14 天里，没有阿鱼提醒、不是从推送点进来，自己回来 ≥ 2 次；并且至少做了一件"面向未来"的事——种谷子、借喜多看家、回复门口的留言、捐菜点桥灯。

收菜和偷菜不算面向未来：它们多半是推送叫来的。

| 指标 | 门槛 | 性质 |
| --- | --- | --- |
| 邀请 30 人 | ≥ 20 人来过 | 前提 |
| 第 7～14 天 | **≥ 10 人住下来** | **主指标** |
| 第 7～14 天 | ≥ 30 次偷菜 | 辅助 |
| 第 7～14 天 | ≥ 15 条留言 | 辅助 |
| 第 7～14 天 | ≥ 20 对好友（含自动） | 辅助 |
| 第 7～14 天 | ≥ 3 条红线牵成 | 辅助 |
| 第 7～14 天 | ≥ 5 条推荐语 | 辅助 |
| 第 7～14 天 | 许愿的人里 ≥ 半数求过 2 次以上签 | 辅助 |

**主指标达到，做阶段 2。主指标不到，辅助再高也不做。** 主指标在 5～10 之间，阿鱼定。

**技术要求**：每次来访记录来源——推送点入、分享卡片点入、自己打开。只有"自己打开"计入"自己回来"。写进任务卡。
