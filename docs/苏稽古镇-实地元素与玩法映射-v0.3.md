## 0. 调研结论

苏稽不是一个"有几个景点"的镇子，是一个**有自己的钟和日历**的镇子：

- 每天：早上豆腐脑摊，白天茶馆和码头，晚上七点半河上夜游
- 逢单日赶场，逢双日安静
- 夏天丰水期，河水漫过桥面
- 元宵有龙灯

镇子好玩的方式不是加景点，是**把这套钟和日历搬进游戏，让真实时间驱动镇上的事**。这和种菜按真实时间长是同一个逻辑。

### 1.0a 两个集市（阿鱼标注带出的玩法）

| | 本地人集市（北） | 游客集市（南） |
| --- | --- | --- |
| 开放 | 逢单日赶场才开 | 天天开 |
| 买入价 | 低 | 高 |
| 卖出价 | 低 | 高 |
| 商品 | 种子、原料、本地小吃 | 纪念品、成品、贵的吃食 |

**跑腿换差价**：在本地集市买或收的东西，走到南边游客集市卖，赚差价，代价是多走两分钟。逢单日本地集市开，人往北；双日只有游客集市，人往南。镇上的人流每天在变。

这是唯一一个不用编的经济玩法——它来自真实地理。

### 1.0b 月老庙（待阿鱼确认）

镇上有月老庙。月老牵红线，游戏叫"红缘大冒险"，核心机制是牵线。

提案：进庙可以给两位朋友牵一条红线，双方都同意才成。红线显示在黄葛树的关系树上，与普通的枝不同色。

## 2. 苏稽的一天（游戏内时间＝真实时间）

| 时段 | 镇上 | 你能做 |
| --- | --- | --- |
| 06:00～10:00 | 豆腐脑摊开，码头有人洗衣 | 早饭（4）、收夜里熟的菜（1） |
| 10:00～18:00 | 老街开门，茶馆有人，逢单日赶场 | 种菜偷菜（1）、串门（1）、工作（4）、赶场买卖（1） |
| 18:00～19:30 | 灯陆续亮 | — |
| 19:30～20:30 | **夜游**，河上灯船，老街挂灯 | 夜游模式看河（5） |
| 20:30～06:00 | 安静，猫在走 | 种菜偷菜（1） |

括号内为阶段。阶段 1 只有：种菜偷菜、串门、赶场、桥面季节视觉。

## 3. 对阶段 1 设计的修改

### 3.1 地图重排

| 原设计 | 改为 |
| --- | --- |
| 河边广场 | **黄葛树下**：桥头，树下石凳，公告板挂在树上，吃席摆在树下 |
| 老街 | **临河老街**：一侧川西民居，一侧峨眉河 |
| 住宅区 | **河对岸**：过桥即到。每来一人多一间 |
| 新人家 | 老街尽头临河那间 |
| 河 | 峨眉河，有码头，阶段 1 只作景 |
| 镇口 | 老街入口的牌坊，回忆册在此 |

**桥是必经之路。** 从老街去住宅区必须过桥。夏天桥面有水花。这是每天都会走过的一段路，也是镇子的记忆点。

| 原 | 改为 | 时长 | 去处 |

### 3.3 共建：点亮 17 孔桥灯

替代原提的"修桥"。桥已经在了，共建的是**桥灯**。

| 项 | 规则 |
| --- | --- |
| 目标 | 茹公桥 17 个桥孔，每孔一盏灯 |
| 点亮一盏 | 全镇累计捐 30 棵菜（任何作物） |
| 捐 | 走到桥头的捐箱，选数量。捐了不给钱 |
| 记名 | 每盏灯下刻这盏灯捐献者的昵称（按捐献量前 5） |
| 全亮 | 17 盏全亮时，晚上桥是镇上最亮的地方。触发一条镇报特刊 |
| 之后 | 阶段 5 加夜游时，桥灯是夜游的一部分 |

成本：一个计数器、17 个开关、一个捐献界面。

### 3.4 赶场

| 项 | 规则 |
| --- | --- |
| 日期 | 公历逢单日 |
| 变化 | 老街多出 3 个临时摊（阶段 1 只是装饰）；卖菜价格 ×2；NPC 人数 ×2；公告板显示"今天赶场" |
| 推送 | 不推。让人自己发现规律 |

成本：日期判断＋价格系数＋摊位显示开关。

### 3.5 桥面季节

6～8 月桥面有水花动画，走过有脚步溅水音效。其他月份干。
