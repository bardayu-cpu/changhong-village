## 用户故事

你走进宴会厅，红毯上方每隔一段，两边灯柱之间挂着一道红绸，中间垂一个绣球，轻轻地晃。到了开席的点，台前一下子飘下来一阵花瓣和彩纸，落满半个屏幕，几秒就散了。你跟邻桌干杯的时候，两个人头顶也落下一小撮花瓣。平时厅里不飘东西，看得清桌子和人。

## 交互说明

- 飘的东西在人和桌子上面、在按钮和牌子下面，**不挡按钮、点不着**，手指照样能点地面走路、点按钮
- 同一时间只放一阵；正在飘的时候又碰到下一个，等这阵散了再放（不叠成一大团）
- 红绸挂在半空：人从下面走过，红绸压在人上面（像真的从下面穿过去）
- 开席那一刻人不在厅里，就不补放；第二天第一次进厅照常放进厅飘落

## 异常处理

| 情况 | 玩家看到 |
| --- | --- |
| 图没到、没下载下来 | 不飘、不挂（不用代码画的色块顶替；调试版可以用色块试） |
| 手机掉帧（02 测出低于 55 帧/秒） | 同时片数减半；红绸不受影响 |
| 开席、干杯同时发生 | 只放开席那阵 |
| 玩家在小游戏、簿子、菜单里 | 不放，回到厅里也不补 |
