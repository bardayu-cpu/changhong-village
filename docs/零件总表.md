> **一件零件一行，编号不随 v1 / v2 变**：文件换版，编号不变，「文件」那一格换成新的。交接单、摆放清单、回执里都写编号。
> `godot/tools/gpt_inbox.py` 每次查交接文件夹会读这张表：GPT 新交的图对得上编号（文件名去掉 `_v数字` 一样，或者文件名里带编号），状态自动改成「交了」，对不上的报出来。**表格的格式别改**（列的顺序、反引号包文件名），不然脚本读不到。

## 状态怎么走

`要画` → `交了` → `02核过` → `阿鱼点头` → `进游戏`

- **要画**：清单里有、GPT 还没交。
- **交了**：共用文件夹里有了（gpt_inbox 自动改）。
- **02核过**：02 过了硬检查（`check_assets.py`：硬边、尺寸）和比例（`scale_check.py`），拼进去看过。
- **阿鱼点头**：阿鱼看过、同意用。
- **进游戏**：打进了给阿鱼扫的那一版码。「进游戏」那一列写哪一版。
- **归GPT**：厨房那批（阿鱼 10/1 定后厨整块归 GPT），这里只列、不填状态，由 GPT 自己管。

同一件零件换了新版（比如桌子交了 v3），状态从「交了」重新走一遍。游戏里用的还是哪一版，看「进游戏」那一列。
