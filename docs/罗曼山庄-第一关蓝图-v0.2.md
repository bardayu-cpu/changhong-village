## 0. 定位

罗曼山庄是苏七镇地图里镇北的一组场景，游戏的第一关。玩家收到请帖到这里：签到、翻回忆册、拍合影、进宴会厅吃席、给新人留悄悄话，再在山庄里逛一圈，出大门往南进镇。

阿鱼 9/15 列的 12 个区域并成 6 块画布：

| 阿鱼说的区域 | 在哪块画布 |
| --- | --- |
| 迎宾、休息区 | 1 迎宾院 |
| 宴会厅 | 2 宴会厅 |
| 化妆室、休息间、麻将室、厨房 | 3 后厅 |
| 草坪、孩童玩闹区 | 4 草坪 |
| 湖边 | 5 湖边 |
| 草莓园、枇杷园 | 6 果园 |

每块画布 32 米宽、32 米深。镜头按现有分层场景的做法：画布高度铺满屏幕，只左右跟人。手机一次看到中间约 12 米宽。

## 2. 主线流程

### 2.1 顺序

```
开场 → 昵称 → 形象（现有）
  ↓
1 迎宾院：从大门走进来（spawn）
  → 新娘妈妈迎一句
  → 签到桌：名字、礼金
  → 领喜糖
  → 新娘妈妈指回忆册和花墙
  → 回忆册（可先翻，可跳过）
  → 花墙合影（可跳过）
  ↓ 楼门
2 宴会厅：走到新人桌写悄悄话（现有）
  → 阿鱼：「吃好了？走 带你回镇上」
  → 大门开
  ↓
自由逛：后厅、草坪、湖边、果园各一件小事
  ↓
1 迎宾院大门：出山庄。阶段 1 到这里结束
```

必经：签到、悄悄话。其余都可跳过，跳过不影响后面。

### 2.2 时长

| 段 | 估计 |
| --- | --- |
| 主线：大门 → 签到 → 拍照 → 悄悄话 → 大门 | 6～8 分钟 |
| 回忆册剪辑 | 2 分钟 |
| 六块逛完 | 再加 5 分钟 |

全部待验证，第一次灰盒跑通后量。

### 2.3 大门和「下一段」

写完悄悄话大门才开。走到大门：阶段 1 显示「镇上的路还没修好 下次带你去」，人停在门口，存档；阶段 2 接进镇路线。文案标「新写」，待阿鱼定。

### 2.4 存什么

| 字段 | 存哪 | 说明 |
| --- | --- | --- |
| 昵称、形象、邀请人 | 服务器（阿鱼 9/15 晚已同意建表） | 邀请人从分享卡片的住民 id 来，这个字段从阶段 2 提前到阶段 1 |
| 座位、敬酒记录、桌簿、好友请求 | 服务器 | 3.2 |
| 签到名字、礼金数 | 服务器，同一条记录 | 只有阿鱼后台能看，不公开 |
| 悄悄话 | 服务器 | 现有，只有阿鱼能看 |
| 喜糖领了、拍过照、大门开了、回忆册翻到哪页 | 本机 | 重进从上次的状态继续 |

**用户故事**：走进大门，新娘妈妈迎上来说这边签到。写下名字，选一个礼金数，新娘爸爸收下说心意收到了。新娘妈妈递一颗喜糖，指着旁边说那本回忆册可以先翻翻，翻完去花墙拍张照，里面已经开席了。

**功能需求**

| 项 | 规则 |
| --- | --- |
| 签到名字 | 默认带昵称，可改，1～12 字，过敏感词 |
| 礼金 | 游戏里的记录，不收费、不扣币、不接支付。选项：不送、66、88、188、自己填（非负整数，上限 9999）。只有阿鱼后台能看，不显示在任何公开的地方 |
| 祝福 | 不单独做。想说的话在宴会厅悄悄话里写（阿鱼 9/15 默认，可改） |
| 喜糖 | 签到后自动收到，本机记一个标记。阶段 1 没有背包，只弹一次「喜糖收好了」 |
| 回忆册 | 见《世界观》1.1 |
| 合影 | 选一个姿势（站好、招手、比心）；两个对焦环靠拢时点一下；早了晚了都不算失败。出一张游戏里的相纸，在屏幕上展示，可以再拍。**阶段 1 不做存相册和带形象的分享图**：微信里读显卡截图会崩（README 微信禁用写法），做法待主程验证。转发用现有卡片 |
| 休息区 | 走到老人旁一句话，一句里最多一个方言词，词表按《乐山话 v0.2》 |
| 出山庄 | 大门只在悄悄话写完后开 |

**交互说明**：走进半径出现按钮；签到面板顺序名字 → 礼金 → 确认，确认页写明「只是游戏里的记录」；合影时人吸附到站位，可小幅左右挪；相纸展示页有「再拍一张」「收好」；重进山庄不重复签到，签到桌只显示「已签到」。

**异常处理**

| 情况 | 处理 |
| --- | --- |
| 名字为空 | 「先留下怎么称呼你」，不提交 |
| 名字有字体显示不出的字 | 现有提示：有个字显示不出来 换一个 |
| 礼金自己填的数超上限 | 按上限 |

| 重复合影 | 每次最多留 3 张，旧的顶掉 |

### 3.2 宴会厅 `scene_roman_banquet`

**一场不散的席。** 全部异步，没有人需要同时在线。你走了，你的人还坐在那桌；别人来了看得到你、能敬你酒、能在你桌的簿子上接一句。

**布局**：以任务卡 A04 通过的 `scene.json` 为准，蓝图只定这几条：

- 舞台在北，主桌在台上靠前，新人站主桌后，红毯 x = 768 直通到底，两侧墙竖直，远近一样大（A04 第二节）。舞台后的圆形山水挂画保留
- **12 张圆桌，每桌 10 把椅子，120 个座**。两边各两列三排，间距按 A01 回执的布局（x = ±4.8、±9.6 米，排距 5.2 米），过道至少 1.2 米
- 桌子积木只画空椅子。坐着的人是真实住民的形象，从服务器读，按座位画在椅子上
- 东侧门 (1500, 600, 50) 通后厅，A04 的底图在东墙靠南留门洞
- 地面、地砖、红毯、墙可以出成瓦片，桌椅、灯笼、花架、屏风仍是积木（A04 补充条款）

**桌的名字**：桌牌由引擎渲染，写「XX 那桌」，XX 是这桌第一个坐下的人。离主桌最近的两桌是阿鱼那桌和 Toretto 那桌。

**用户故事**：走进厅，新娘妈妈说你坐老王那桌，老王带你来的。坐下，桌上一本簿子，前面三个人写了三句，接一句。隔壁桌有个头像眼熟，走过去坐到空椅子上，点一下，敬一杯。第二天回来，簿子多了两句，他回敬了一杯，桌上多了个新人，小李带进来的。

**功能需求**

| 动作 | 规则 |
| --- | --- |
| 入座 | 第一次进厅自动分座：坐带你进来的人那桌；那桌满 10 人就坐同枝的下一桌；阿鱼和 Toretto 带的人坐离主桌最近的两桌。没有邀请人的（阿鱼后台直接加的）坐任意空桌 |
| 换桌 | 走到任何一桌的空椅子，点「坐这儿」，座位改到这桌，下次来还在。每次来访只能换一次。换走后原座位空出 |
| 看人 | 点一个坐着的人，只显示四样：昵称、形象、「XX 带进来的」、他那一条住民动态。没有自我介绍、没有 MBTI、没有标签（GDD §14 不做自述卡） |
| 敬酒 | 点人 → 「敬一杯」。对方下次来看到「XX 敬了你一杯」，可回敬一次。每人每天 5 杯，对同一人每天 1 杯。敬过酒的两人互相进「可能认识的人」（阶段 1 设计 3.10 的信号里加一条：敬过酒） |
| 桌簿 | 每桌一本，坐过的桌都能写，接龙显示，一条不超过 100 字，过敏感词。簿子跟桌走。只有阿鱼后台能删 |
| 加好友 | 走原规则：同枝自动；同桌、敬过酒的人可以发「想认识你」 |
| 主桌 | 不变：走到主桌前写悄悄话，只有阿鱼看得到。新人不坐，站主桌后 |
| 座位上限 | 120。满了新来的人坐在墙边的长凳上，长凳无限，能做所有动作 |

**交互说明**

- 走到空椅子出「坐这儿」；已经坐着的椅子走近出那个人的名字，点开四样加两个按钮「敬一杯」「想认识你」
- 自己的座位有一个小标记；换桌前弹一句「换到 XX 那桌？今天只能换一次」
- 簿子在桌心，走到桌边任一处出「翻簿子」，翻开是接龙列表，最下面输入框
- 敬酒和被敬的记录、簿子新句子，进厅时用一条提示合并显示：「老王敬了你一杯，簿子上多了 2 句」
- 全部读写走服务器，客户端只做即时预览；断网时能走不能坐、不能写

**异常处理**

| 情况 | 处理 |
| --- | --- |
| 两人几乎同时坐同一把椅子 | 服务端先到先得，后到的提示「这把有人坐了」，人站在椅子旁 |
| 今天已换过桌 | 按钮置灰，提示「今天换过了 明天再换」 |
| 今天 5 杯敬完 | 「今天敬够了」 |
| 对同一人今天敬过 | 「这杯敬过了」 |
| 簿子有敏感词 | 沿用昵称校验的提示，不写入 |
| 邀请人是被封的枝 | 按无邀请人处理，坐任意空桌 |
| 邀请人还没坐过 | 给邀请人和自己开一桌，桌牌写自己的名字 |
| 断网 | 能走，坐、敬、写都提示「没连上 再试一下」 |

**阶段 1 做什么**：入座、换桌、看人、敬酒、桌簿、悄悄话全部做。「想认识你」的好友关系本身在阶段 2，阶段 1 只记请求。
