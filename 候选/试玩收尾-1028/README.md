本机导出：`python3 候选/试玩收尾-1028/build.py --export mac`，再分别执行 `--export web`、`--export qa`。三份输出先进入本轮测试目录的「重打-1028.5」，不覆盖在用包。确认Mac/QA均已正常退出、手机服务已停止，再执行 `python3 候选/试玩收尾-1028/finalize.py --publish-after-GUI-release`；该步骤检查三份完整包索引、保存配置、签名和来源后才发布稳定入口。需要官方Godot4.7.2及同版Mac、单线程Web模板。
